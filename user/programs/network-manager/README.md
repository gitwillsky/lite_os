# 网络管理器

从控制面板打开「网络管理器」，输入主机名、IPv4 或 IPv6 地址。选择「Ping」查看应答、丢包率和往返时间，或选择「逐跳探测」查看应答的各跳及其往返时间。`*` 表示这一跳的探测未在等待时间内收到应答。

结果随探测输出更新。「停止」结束本次探测并保留已收到的结果。关闭窗口会取消正在运行的探测。两项操作使用当前账户的 `CAP_NET_RAW` 权限，管理员桌面可直接运行。

探测复用产品安装的 BusyBox `ping` 与 `traceroute`，各运行一次并受总时限约束。命令行用法见[系统网络诊断](../../base/README.md#命令行网络诊断)，进程与退出边界见[用户态接口契约](../../../docs/architecture-contract/userspace-abi.md#网络管理入口)。

当前 IPv6 Ping 的 `ttl=-1` 表示未取得应答的剩余跳数。应答、丢包率和往返时间仍按实际探测结果显示。

### 带宽测试

在对端启动 `iperf3 -s -1 --idle-timeout 30`，然后在「网络诊断」填写对端主机名或 IPv4/IPv6 地址。默认端口为 5201，也可填写对端指定的端口。选择「测上传」或「测下载」，持续 10 秒，逐秒显示速率，结束后以接收端统计显示平均速率。

「停止」可取消测试，已显示的结果会保留。LiteOS 已预装 `iperf3`，也可在终端临时作为测试对端。测速产生实际网络流量。[ESnet 用法](https://github.com/esnet/iperf/blob/3.22/docs/invoking.rst)

## 配置备份

在「配置备份」页查看现有备份、自动任务状态和下次运行时间。「刷新」重新读取当前结果。「创建备份」保存当前路由配置，选中某一份后可导出、删除或恢复。

点击「定时设置…」可以启用或停用自动备份，设置间隔和保留份数，再审阅并提交。停用会保留已有备份。打开设置后若有其他配置提交，重新打开以读取当前设置。

导出文件可能包含认证密钥。请选择新的文件名，导出会以私有权限创建文件。恢复将替换当前路由设置，确认期间若配置有变动，系统会拒绝此次恢复。结果未确认时，可用显示的提交编号查询保存结果。

备份操作需要 root 或 `netdev` 组权限。命令行支持[设置定时策略](../../libraries/network-config/README.md#备份与恢复)和[查询提交结果](../../libraries/network-config/README.md#审阅配置)。

## 路由配置

在「路由配置」页用「读取当前」或「导入文件」载入 JSON 草稿。「字段说明」导出配置的 JSON Schema。「导出草稿」将编辑内容写入新的私有文件，供以后继续编辑。
例如，在现有草稿的顶层加入 `"backup":{"interval_seconds":86400,"retain":10}`，可每天备份并保留最近十份自动备份。

打开旧版网络设置备份时，可在「导入文件」中切换到「所有文件」。系统会将通过校验的旧二进制文件转成可编辑草稿，管理员可审阅差异后提交。

「审阅」校验草稿，按路径分页列出改动。选择一项可查看修改前后的值。可按路径或值查找改动，较长的值可逐页查看。核对后选择「提交」。
如果当前设置无法加载，审阅会列出待恢复的内容。审阅期间或确认后发生配置变化时，重新审阅再提交。

提交后显示编号和当前应用状态。「应用状态」可重新查询。提交结果未确认时，先查询该编号并核对当前配置。窗口关闭或换入其他草稿前会询问是否放弃未保存的修改。
配置管理需要 root 或 `netdev` 组权限。大于 16 MiB 的文件可在桌面导入、导出、审阅和提交。文本编辑适用于 16 MiB 以内的草稿。

### 独立路由域

从「路由表」选择「路由设置…」。在「路由域」下拉框切换默认域和具名域，或用「新建域…」建立独立网络。
选择目标域后点「分配网卡…」，按网卡硬件地址和原归属选择设备，可同时设置它在目标域中的配置名称。

移入具名域时，网卡保留可用的地址和接口设置。原有 DHCP 和 IPv4 DNS 设置需要确认后移除。网桥端口须先退出原网桥。
移动后请核对原域引用该网卡的设置，尤其是默认域 BGP 的链路本地邻居所用的运行时接口名称。

在具名域可编辑接口、双栈转发、静态路由、备选表、选路规则、防火墙、NAT、BGP 和 OSPF。地址分发与 DNS、网桥和 VLAN 在默认域设置。
不同域的改动可在一次审阅中提交，取消路由设置可放弃整份草稿。

删除具名域会删除其中的设置，网卡会回到默认域并采用默认设置。若要保留网卡的静态设置，可先在默认域分配该网卡，再删除原域。
按域启动程序和命令行查询见[路由域使用说明](../../libraries/network-config/README.md#建立独立静态路由域)。

### 转发专用 CPU

管理员可打开「路由表 → 路由设置… → 转发专用 CPU…」，输入一个或多个在线逻辑 CPU 编号，用逗号分隔，再审阅并提交。留空恢复共享调度。该设置适用于所有路由域，提交后无需重启。

系统须保留至少一颗共享 CPU。多颗专用 CPU 可同时处理不同路由域的流量。目标 CPU 不在线、已被其他服务独占，或有必须留在该 CPU 的任务时，系统会保留原分配。可在「路由配置」页重新查询应用状态。

### 按域查看运行状态

在「路由表」「邻居」「转发连接」或「防火墙计数」页，从窗口顶部选择「路由域」。切换后各页从所选域的第一页重新读取。BGP 和 OSPF 窗口也使用打开时选择的域。
管理员提交新增或删除后，可点「刷新域」更新名称列表。所选域被删除时，选择其他域继续查看。

## 转发连接

打开「转发连接」页可查看所选域已跟踪的 IPv4 和 IPv6 连接。列表显示协议、最初的源和目标地址及状态。切换页面浏览，每页最多 64 条。打开时自动更新，切到其他页后暂停观察。

root、`netdev` 或 `netview` 成员可查看。root 和 `netdev` 成员可选择一条记录并确认「清除连接」。如观察中断，选择「刷新」重读当前页。未配置连接状态匹配或地址转换的流量可能未被跟踪。

## 防火墙计数

在「防火墙计数」页查看预路由入口和子链的规则、命中报文数及 IP 字节数。选中一行可查看匹配条件和完整动作。每页最多 64 条，当前页每秒采样，有变化时更新，离开后停止观察。

root、`netdev` 或 `netview` 成员可查看。规则换版时，后续页会回到首页。如观察中断，点击「刷新」重新订阅。

## 邻居

在「邻居」页查看所选域中 IPv4 ARP 和 IPv6 ND 发现的邻居。每条记录显示所属接口、IP 地址、已学习的 MAC 地址和可达状态，IPv6 邻居的路由器身份也会显示。

root、`netdev` 或 `netview` 成员可查看。当前页每秒采样，有变化时更新。翻页可查看后续记录，离开该页停止观察。如观察中断，点击「刷新」恢复。

## 路由表

在「路由表」页切换 IPv4 或 IPv6，查看所选域已安装的目的网段、路由表、出口、下一跳与权重。多路径路由按成员逐行显示，翻页可继续查看同组的成员。选择一行可查看完整地址、来源、度量和首选源。

root、`netdev` 或 `netview` 成员可查看。每页最多 64 条路径，当前页每秒采样，有变化时更新。路由变化可能改变后续页的位置。如观察中断，点击「刷新」恢复。

### OSPF 邻居

在「路由表」点击「OSPF 邻居…」，查看各接口上已启用的 OSPFv2 和 OSPFv3、邻居地址及同步状态。尚无邻居的链路也会显示。选中一行可查看区域、本地地址、认证方式、拒绝次数和最近的拒绝原因。点击「刷新」读取当前状态。

root、`netdev` 或 `netview` 成员可查看。

### OSPF 设置

root 和 `netdev` 成员可从「路由表 → 路由设置… → OSPF…」设置路由器 ID，为路由接口或 VLAN 网关启用 OSPFv2、OSPFv3，配置区域、代价与邻居检测间隔。「仅通告本网段」适用于无需建立邻接的局域网。「停用 OSPF」可停用全部接口。

在对应版本的「认证…」中新增、替换或删除共享密钥，选择用于发送的编号。保留的密钥都可用于接收。停用该版本或改为仅通告后，该版本的认证随配置一同关闭。密钥正文在审阅中显示为「已隐藏」。

点击「确定」回到路由设置，再通过「审阅…」统一提交。提交后可打开「OSPF 邻居…」查看邻接和认证结果，在「路由表」查看学到的路由。[链路配置与换钥](../../libraries/network-config/README.md#ospf-邻居认证)

### BGP 会话和路由

在「路由表 → BGP…」查看邻居地址、会话状态、收到与已发布的路由数。选中邻居可查看认证、协商的地址族和多路径能力，以及最近的连接错误。点击「刷新状态」重新读取。

点击「查询前缀…」并输入 IPv4 或 IPv6 网段，查看收到的路径、未选用的原因、已确认的 BGP 选择及各邻居的宣告情况。选中路径可查看下一跳、AS 路径、路径编号和团体属性。实际转发结果在「路由表」查看。

root、`netdev` 或 `netview` 成员可查询。root 和 `netdev` 成员可选中已建立的邻居，按地址族请求路由重发。界面确认的是请求已排队。可再次查询前缀核对收到的路径。[路由刷新](../../../docs/architecture-contract/bgp.md#邻居请求路由重发)

root 和 `netdev` 成员可选中一个邻居，点击「停用…」或「启用…」，审阅后提交。停用会保留邻居配置并重新选择受影响的路由，其余 BGP 会话继续运行。

### BGP 设置

root 和 `netdev` 成员可从「路由表 → 路由设置… → BGP…」设置本地 AS、路由器 ID 和反射簇，也可在「AS 联盟…」配置公开 AS 及成员 AS。

在邻居列表新增、编辑或删除邻居。填写对端地址和 AS，选择 IPv4、IPv6 单播及多路径收发方向。IPv6 链路本地地址须填写实际接口名称。新邻居的管理距离、保持时间、重试间隔初始为 20、90 秒和 5 秒，可按需修改。

在邻居属性的「认证…」选择 TCP MD5 或 TCP-AO。已有密钥输入留空时沿用原密钥。TCP-AO 可同时保留多把密钥，分别选择当前发送和首选接收编号。已启用 TCP-AO 的邻居可先加入新密钥，再切换编号、移除旧密钥。审阅时会标出密钥变更，密钥正文隐藏。[认证与换钥](../../../docs/architecture-contract/tcp-authentication.md#bgp-配置与操作)

在「路由宣告…」添加本机 IPv4 或 IPv6 网段。可选择重分发直连网段或填写其他协议编号，例如静态路由 `4`、OSPF `188`。实际发布仍受出口策略约束。修改后回到路由设置，通过「审阅…」统一提交。[BGP 路由配置](../../libraries/network-config/README.md#bgp-配置)

### BGP 路由策略

在邻居属性中打开「入口策略…」或「出口策略…」，新增、编辑、删除或上下移动规则。首个满足全部条件的规则生效。都未匹配时执行所选的默认动作。移除策略后，该方向恢复缺省拒绝。入口策略也可设置本地优先值。

条件可使用双栈网段和前缀长度范围、ORIGIN、MED、本地优先值、AS 路径和三类团体。范围可输入单值或两个端点，例如 `10-20`。允许规则可设置下一跳、调整选路属性、改写 AS 路径，并替换、删除或添加团体。勾选替换并留空可清空相应团体集合。

确认后回到路由设置，点击「审阅…」提交。在「BGP… → 查询前缀…」核对入口判定和各邻居的宣告情况。[BGP 策略契约](../../../docs/architecture-contract/bgp.md#入口政策反馈选路与发表)

### 静态路由

在「路由表」点击「路由设置…」，选择主路由表或备选表。可分页浏览或输入完整网段查找，然后新增、编辑或删除静态路由。
转发路由支持多个带权下一跳，可选择直连接口或填写递归下一跳。也可设置丢弃、不可达或禁止。优先级数值越小越优先。
root 和 `netdev` 成员可编辑。点击「审阅…」核对本次全部修改后提交。其他人已修改配置时需重新打开并核对。关闭窗口前会询问是否放弃未提交的修改。生效结果可回到「路由表」查看。

### 备选表与选路规则

在「路由设置」点击「新建表…」并输入表号，再在新表中添加静态路由。系统保留表号 253–255。「删除表」同时删除表中的路由，已有规则引用时需先调整规则。

打开「选路规则…」新增、编辑或删除规则。选择本机或转发流量，填写源网段和目标表。转发可指定入接口，两种流量均可按报文标记匹配。标记和掩码支持十进制或 `0x` 前缀的十六进制，标记留空时匹配任意值。
数字较小的优先级先匹配。点击「返回」后可继续编辑，再一次审阅和提交路由表、静态路由及选路规则。[查询生效规则和实际路径](../../../docs/architecture-contract/ip-forwarding.md#策略选路)

### 路由接口与双栈转发

在「路由设置」打开「路由接口…」。列表同时显示当前网卡和已保存的配置，未连接的设备仍可修改。
选中网卡打开「属性…」，可以设定显示名称、管理状态、MTU 和默认路由优先级。首次为当前网卡保存属性时按 MAC 绑定，重启后也可识别。

「IPv4…」可选择沿用系统默认、DHCP 或手动设置，并填写地址、前缀、网关、DNS 和连接后缀。「IPv6…」可添加多个静态地址，逐个指定是否安装直连前缀，并选择何时接受上联路由通告。网桥端口的三层地址在对应的 VLAN 网关设置。

列表上方可独立启停 IPv4 与 IPv6 转发，影响接口间经过的流量。返回后点击「审阅…」，可将接口、转发开关、静态路由和选路规则一并提交。[转发语义](../../../docs/architecture-contract/router-configuration.md#双栈转发开关)

### 地址分发与 DNS

在「路由设置」打开「地址分发与 DNS…」，选择物理下游接口或已有 VLAN 网关。

- 「DHCPv4…」设置分发范围、客户端网关和 DNS、租期以及分配前的冲突检查。接口须有静态 IPv4。用 `ipconfig /leases <接口名>` 查看当前租约。[地址池要求](../../libraries/network-config/README.md#dhcpv4-地址池)
- 「IPv6 通告…」设置通告间隔、默认网关寿命和客户端 DNS。静态直连 `/64` 与上联委派到该接口的前缀可同时通告。网关寿命填 0 时，客户端不会从该通告取得默认网关。[下游路由通告](../../../docs/architecture-contract/ipv6-link.md#下游路由通告)
- 「IPv6 前缀委派…」选择物理上联，填写稳定的 DUID MAC 与 IAID，为已启用通告的下游分配不同子网编号。可信上联可启用认证重配置。系统须开启 IPv6 转发，上联须有 IPv6 默认路径。[委派要求](../../libraries/network-config/README.md#dhcpv6-前缀委派)
- 「DNS 设置…」可修改主后缀和搜索域，或启用下游转发与缓存。监听地址从已配置的静态地址中选择。上游可调整顺序，链路本地 IPv6 上游须指定接口。
  将监听地址填入下游 DHCPv4 或 IPv6 通告的 DNS 列表，客户端即可使用该解析器。[DNS 转发](../../../docs/architecture-contract/dns-forwarding.md)

返回「路由设置」后统一审阅和提交。启用地址分发或通告前，请确认选中了实际承载下游设备的接口。

### 网桥与 VLAN

在「路由设置」打开「网桥与 VLAN…」，新建或编辑网桥，设置快速生成树及网桥优先级。「物理端口…」可加入已保存配置的物理网卡。
首次使用一块网卡时，可在「路由接口」打开属性并确定，保留默认值也会建立配置。带三层配置的端口加入网桥前，会提示确认清除端口上的地址、默认路由、地址池和通告。

端口的「入口 PVID」用于无标签及优先级标签帧，可留空以拒绝此类入口帧。带标签和去标签出口分别填写 VLAN 编号，支持 `10 20-24` 这样的列表。
可独立设置端口隔离、边缘端口、点到点链路和路径代价。边缘模式用于直接连接终端的端口。[网桥语义](../../../docs/architecture-contract/switching.md)

为需要三层地址的 VLAN 添加网关，选择成员 VLAN，设置接口名称和静态 IPv4 或 IPv6。网关保存到草稿后，可继续配置地址分发、DNS、静态路由和选路规则。
修改接口名称或移除网关时，在同一草稿里更新引用它的路由和服务，再审阅提交。

### 防火墙与 NAT

在「路由设置」打开「防火墙与 NAT…」。选中预路由入口或子链后打开「规则…」，可以新增、编辑、删除或移动规则。新增规则插在选中项之后，未选中时追加到末尾。规则按显示顺序执行。

规则可按入接口、双栈源网段、目的网段或目的地址集、连接状态以及 TCP 或 UDP 的目的端口匹配。可放行、丢弃、设置路由标记、跳转到子链或返回。
「目的地址集…」按行录入网段。删除地址集或子链前，先移除相关规则的引用。

NAT 可设置固定目的或源地址，也可使用实际出口地址。目的转换可同时配置源转换。改写端口时须在规则中指定 TCP 或 UDP。端口留空时保留原端口，自动源地址转换会处理源端口冲突。
可选择让已有转发连接沿用修改前的规则。返回后统一审阅提交，在「防火墙计数」查看生效规则和命中统计。[规则与连接行为](../../../docs/architecture-contract/ip-forwarding.md#预路由规则)

## 接口流量

打开「接口流量」，查看本机各接口的接收和发送速率、累计流量以及丢包数。选中接口可看累计报文、字节数和收发错误。首次读取、刚出现的接口或计数重置后，速率显示为「—」，等下次采样后更新。

root、`netdev` 或 `netview` 成员可查看。每页最多 64 个接口，离开该页停止观察。如观察中断，点击「刷新」恢复。物理接口、VLAN 和回环各自显示计数，同一流量可能经过多个接口。

### 实时流量分析

在「接口流量」选中接口，点击「流量分析…」。窗口按秒刷新主要流量的收发方向、协议、源、目的、速率和字节占比，下方保留最近 10 次采样。
「≥」表示当前统计能确认的下界。「其他或未确定」包括未列出的流量和未能精确归属的字节。采集丢包数单独显示，出现丢包时该窗只统计实际读取到的流量。
本地 root 和 `netdev` 成员可使用。关闭窗口即停止采集。

### 抓包

在「接口流量」选中接口，点击「抓包…」并选择新的 `.pcap` 文件。可切换到其他页面继续操作。点击「停止抓包」会保存已抓到的报文并显示抓包缓冲丢弃数。接口移除、满 60 秒或达到 64 MiB 时会自动停止保存。

本地 root 和 `netdev` 成员可抓取该接口收发的报文。保存的文件可用 Wireshark 或 `tcpdump -r` 打开。启用网卡发送校验和卸载时，文件中的部分发送报文可能显示未完成的校验和。
