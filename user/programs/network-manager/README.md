# 网络管理器

从桌面打开「网络管理器」。界面按 WinBox 布局：标题栏显示「用户@主机」，顶栏选择路由域。底部状态栏显示主机与系统版本、CPU 占用、内存（已用 / 可用 / 总量）、运行时间和本地时间，每秒更新。
左侧深蓝竖条下是平面菜单，按「接口」「网桥」「IP」「路由」「系统」「工具」组织功能。带 ▸ 的项在右侧弹出子菜单，也可在菜单获得焦点后用方向键和回车选择。
单击「接口」、在「路由」选「路由表」、在「IP」选「防火墙」，可以同时查看三个窗口。「新终端」打开独立的系统终端，「退出」关闭网络管理器。
拖标题栏移动，拖右下角缩放，点击露出的窗口将它置前。单击右上角 × 或按 Ctrl+F4 关闭当前子窗口，Ctrl+F6 在已打开的子窗口之间切换。关闭观察窗口会停止对应的实时查询。
「路由」还提供 BGP 会话、OSPF 邻居和路由准入；「IP」还提供地址、ARP 和地址分发；「工具」提供 Ping、路由跟踪和带宽测试，各是独立窗口。

「IP → 地址」列出所选域各网卡的 IPv4 地址、网段、接口和网关，每两秒更新。标志 D 表示经 DHCP 取得；具名域显示已保存的静态地址。双击打开该网卡的 IPv4 设置，「删除」清除其地址设置，两者都直接提交；「新建」打开路由接口设置。

列表窗口顶部是工具栏：「新建」「删除」「启用」「停用」带文字，翻页、刷新和筛选只有图标，悬停显示名称，不可用的按钮显示为灰色。首列是标志：接口的 X 表示停用；路由的 D 动态、A 生效，后缀 c 直连、s 静态、d DHCP、b BGP、o OSPF。
右侧「动作」面板列出针对所选条目的命令。底部状态栏依次显示本页条目数、已选数和观察状态。双击或回车打开所选条目的属性窗口。

桌面应用随 `liteos-network-manager` APK 安装。管理员可用 `apk del liteos-network-manager` 删除应用与桌面入口，用 `apk add /路径/liteos-network-manager-0.1.0-r0.apk` 重新安装。
构建输出在 `target/packages/<arch>/<指纹>/`。应用包的生命周期独立于原生网络服务。完整路由扩展的安装和卸载见[路由计划](../../../docs/plans/router.md#todo待实现功能)。

在「工具 → Ping」或「工具 → 路由跟踪」输入主机名、IPv4 或 IPv6 地址并点「开始」，查看应答、丢包率和往返时间，或应答的各跳及其往返时间。`*` 表示这一跳的探测未在等待时间内收到应答。

结果随探测输出更新。「停止」结束本次探测并保留已收到的结果。关闭窗口会取消正在运行的探测。两项操作使用当前账户的 `CAP_NET_RAW` 权限，管理员桌面可直接运行。

探测复用产品安装的 BusyBox `ping` 与 `traceroute`，各运行一次并受总时限约束。命令行用法见[系统网络诊断](../../base/README.md#命令行网络诊断)，进程与退出边界见[用户态接口契约](../../../docs/architecture-contract/userspace-abi.md#网络管理入口)。

当前 IPv6 Ping 的 `ttl=-1` 表示未取得应答的剩余跳数。应答、丢包率和往返时间仍按实际探测结果显示。

在顶栏选择路由域后，「工具」的 Ping、路由跟踪和带宽测试会使用该域。窗口左侧填写目标地址（带宽测试还有端口），右侧是「开始」「停止」等按钮。结果按列显示：Ping 为序号、主机、时间、大小和 TTL，路由跟踪为跳、地址和往返时间，统计显示在状态栏。具名域探测需要加入网络命名空间的权限，管理员可直接运行。结果标明启动本次探测时选定的域。主机名仍按系统解析设置处理，具名域排查可直接填写 IP 地址。

### 带宽测试

在对端启动 `iperf3 -s -1 --idle-timeout 30`，然后在「工具 → 带宽测试」填写对端主机名或 IPv4/IPv6 地址。默认端口为 5201，也可填写对端指定的端口。选择「测上传」或「测下载」，持续 10 秒，逐秒显示速率，结束后以接收端统计显示平均速率。

「停止」可取消测试，已显示的结果会保留。LiteOS 已预装 `iperf3`，也可在终端临时作为测试对端。测速产生实际网络流量。[ESnet 用法](https://github.com/esnet/iperf/blob/3.22/docs/invoking.rst)

## 配置备份

在「配置备份」页查看现有备份、自动任务状态和下次运行时间。「刷新」重新读取当前结果。「创建备份」保存当前路由配置，选中某一份后可导出、删除或恢复。

点击「定时设置…」可以启用或停用自动备份，设置间隔和保留份数，再审阅并提交。停用会保留已有备份。打开设置后若有其他配置提交，重新打开以读取当前设置。

导出文件可能包含认证密钥。请选择新的文件名，导出会以私有权限创建文件。恢复将替换当前路由设置，确认期间若配置有变动，系统会拒绝此次恢复。结果未确认时，可用显示的提交编号查询保存结果。

备份操作需要 root 或 `netdev` 组权限。命令行支持[设置定时策略](../../libraries/network-config/README.md#备份与恢复)和[查询提交结果](../../libraries/network-config/README.md#审阅配置)。

## 路由配置

在「路由配置」页用「读取当前」或「导入文件」载入 JSON 草稿。「字段说明」导出配置的 JSON Schema。「导出草稿」将编辑内容写入新的私有文件，供以后继续编辑。
例如，在现有草稿的顶层加入 `"backup":{"interval_seconds":86400,"retain":10}`，可每天备份并保留最近十份自动备份。

打开旧版网络设置备份时，可在「导入文件」中切换到「所有文件」。系统会将通过校验的旧二进制文件转成可编辑草稿，管理员可审阅差异后提交。

「审阅」校验草稿，按路径分页列出改动。选择一项可查看修改前后的值。可按路径或值查找改动，较长的值可逐页查看。核对后选择「提交」。
如果当前设置无法加载，审阅会列出待恢复的内容。审阅期间或确认后发生配置变化时，重新审阅再提交。

提交后显示编号和当前应用状态。「应用状态」可重新查询。提交结果未确认时，先查询该编号并核对当前配置。窗口关闭或换入其他草稿前会询问是否放弃未保存的修改。
配置管理需要 root 或 `netdev` 组权限。大于 16 MiB 的文件可在桌面导入、导出、审阅和提交。文本编辑适用于 16 MiB 以内的草稿。

### 独立路由域

从「路由 → 路由域与选路」打开路由设置。在「路由域」下拉框切换默认域和具名域，或用「新建域…」建立独立网络。
选择目标域后点「分配网卡…」，按网卡硬件地址和原归属选择设备，可同时设置它在目标域中的配置名称。

移入具名域时，网卡保留地址获取方式、下游 DHCPv4 地址池和可用接口设置。手动 IPv4 DNS 覆盖需要确认后移除。网桥端口须先退出原网桥。
移动后请核对原域引用该网卡的设置，尤其是默认域 BGP 的链路本地邻居所用的运行时接口名称。

在具名域可编辑接口、网桥和 VLAN、双栈转发、静态路由、备选表、选路规则、防火墙、NAT、BGP、OSPF、下游 DHCPv4、IPv6 通告和 DNS 转发。默认域还可设置系统 DNS 搜索域。
不同域的改动可在一次审阅中提交，取消路由设置可放弃整份草稿。

删除具名域会删除其中的设置，网卡会回到默认域并采用默认设置。若要保留网卡的静态设置，可先在默认域分配该网卡，再删除原域。
按域启动程序和命令行查询见[路由域使用说明](../../libraries/network-config/README.md#建立独立静态路由域)。

### 转发专用 CPU

管理员可在路由设置中打开「转发专用 CPU…」，输入一个或多个在线逻辑 CPU 编号，用逗号分隔，再审阅并提交。留空恢复共享调度。该设置适用于所有路由域，提交后无需重启。

系统须保留至少一颗共享 CPU。多颗专用 CPU 可同时处理不同路由域的流量。目标 CPU 不在线、已被其他服务独占，或有必须留在该 CPU 的任务时，系统会保留原分配。可在「路由配置」页重新查询应用状态。

### 按域查看运行状态

在顶栏的「路由域」下拉框选择域，「工具」各窗口及「路由表」「地址」「ARP」「IPv6 邻居」、双栈防火墙和「接口」窗口都使用该域。切换后观察窗口从所选域的第一页重新读取。BGP、OSPF 和流量分析使用打开时选择的域。
管理员提交新增或删除后，可点下拉框旁的刷新按钮更新名称列表。所选域被删除时，选择其他域继续查看。

## 转发连接

从「IP → 防火墙 → 连接」查看 IPv4 转发连接，从「IPv6 → 防火墙 → 连接」查看 IPv6 转发连接。列表按所选域实时显示原方向的端点、回复方向的地址、协议、TCP 阶段和跟踪标志。经过 NAT 的连接显示转换后的回复端点。双击条目可查看回复端口及标志的只读属性。

root、`netdev` 或 `netview` 成员可查看。root 和 `netdev` 成员可从工具栏或属性窗口选择「删除」并确认。条目到期或清除后，列表移除该条，相关属性窗口随之关闭。每页最多 64 条，翻页或切换路由域时重新加载。如观察中断，选择「刷新」重读当前页。未配置连接状态匹配或地址转换的流量可能未被跟踪。

## 防火墙计数与规则

在「IP → 防火墙」或「IPv6 → 防火墙」选择「过滤规则」或「NAT」。选中条目可启停或删除，双击可编辑。新建规则只匹配当前地址族，追加到预路由入口链。规则仍按保存的链内顺序执行，现有子链规则可在原位置修改。

双栈共享的旧规则在两侧都可见，修改前会提示影响范围。这些规则的合计计数可用 `ipconfig /firewall` 查看。单地址族规则显示命中报文数和 IP 字节数，当前页每秒更新，规则换版时回到首页。

root、`netdev` 或 `netview` 成员可查看，修改由管理端点校验提交权限和配置代际。已停用规则保留链内位置，启用后在原位置参与匹配。批量调整、排序、地址集和子链仍可从「路由设置」进入。

## 邻居

在「IP → ARP」查看 IPv4 地址解析记录，在「IPv6 → 邻居」查看 IPv6 ND 记录。两窗口按所选 VRF 实时显示地址、已学习的 MAC、接口和可达状态，标志 D 表示动态，C 表示已取得 MAC。双击打开只读属性，记录离开当前页后属性关闭。

root、`netdev` 或 `netview` 成员可查看。当前页每秒采样，有变化时更新。翻页可查看后续记录，离开该页停止观察。如观察中断，点击「刷新」恢复。

## 路由表

在「路由表」工具栏右端的下拉框切换 IPv4 或 IPv6，查看所选域已安装的目的网段、路由表、出口、下一跳与权重。多路径路由按成员逐行显示，翻页可继续查看同组的成员。选择一行可查看完整地址、来源、度量和首选源。

在「查找」框输入规范 CIDR 网段后回车或点漏斗按钮，可查看该目的网段在所选域各表的路径，地址族随输入切换。清空输入后再次筛选，恢复该族的完整列表。

root、`netdev` 或 `netview` 成员可查看。每页最多 64 条路径，当前页每秒采样，有变化时更新。路由变化可能改变后续页的位置。如观察中断，点击「刷新」恢复。

### OSPF 邻居

在「路由 → OSPF 邻居」查看各接口上已启用的 OSPFv2 和 OSPFv3、邻居地址及同步状态。尚无邻居的链路也会显示。选中一行可查看区域、本地地址、认证方式、拒绝次数和最近的拒绝原因。点击「刷新」读取当前状态。

root、`netdev` 或 `netview` 成员可查看。

### OSPF 设置

root 和 `netdev` 成员可从「路由 → OSPF 设置」设置路由器 ID，为路由接口或 VLAN 网关启用 OSPFv2、OSPFv3，配置区域、代价与邻居检测间隔。「仅通告本网段」适用于无需建立邻接的局域网。「停用 OSPF」可停用全部接口。

共享以太网上填写「广播优先级」，启用广播模式并参与 DR/BDR 选举。优先级填 0 时不参选，留空时使用点到点。「OSPF 邻居」可查看 DR、BDR 和双向邻居进入的 2-Way 或 Full 状态。

在对应版本的「认证…」中新增、替换或删除共享密钥，选择用于发送的编号。保留的密钥都可用于接收。停用该版本或改为仅通告后，该版本的认证随配置一同关闭。密钥正文在审阅中显示为「已隐藏」。

点击「确定」回到路由设置，再通过「审阅…」统一提交。提交后可打开「路由 → OSPF 邻居」查看邻接和认证结果，在「路由表」查看学到的路由。[链路配置与换钥](../../libraries/network-config/README.md#ospf-邻居认证)

### BGP 会话和路由

在「路由 → BGP 会话」查看邻居地址、会话状态、收到与已发布的路由数。选中邻居可查看认证、协商的地址族和多路径能力，以及最近的连接错误。点击「刷新状态」重新读取。

点击「查询前缀…」并输入 IPv4 或 IPv6 网段，查看收到的路径、未选用的原因、已确认的 BGP 选择及各邻居的宣告情况。选中路径可查看下一跳、AS 路径、路径编号和团体属性。实际转发结果在「路由表」查看。

root、`netdev` 或 `netview` 成员可查询。root 和 `netdev` 成员可选中已建立的邻居，按地址族请求路由重发。界面确认的是请求已排队。可再次查询前缀核对收到的路径。[路由刷新](../../../docs/architecture-contract/bgp.md#邻居请求路由重发)

root 和 `netdev` 成员可选中一个邻居，点击「停用…」或「启用…」，审阅后提交。停用会保留邻居配置并重新选择受影响的路由，其余 BGP 会话继续运行。

### BGP 设置

root 和 `netdev` 成员可从「路由 → BGP 设置」设置本地 AS、路由器 ID 和反射簇，也可在「AS 联盟…」配置公开 AS 及成员 AS。

在邻居列表新增、编辑或删除邻居。填写对端地址和 AS，选择 IPv4、IPv6 单播及多路径收发方向。IPv6 链路本地地址须填写实际接口名称。新邻居的管理距离、保持时间、重试间隔初始为 20、90 秒和 5 秒，可按需修改。

在邻居属性的「认证…」选择 TCP MD5 或 TCP-AO。已有密钥输入留空时沿用原密钥。TCP-AO 可同时保留多把密钥，分别选择当前发送和首选接收编号。已启用 TCP-AO 的邻居可先加入新密钥，再切换编号、移除旧密钥。审阅时会标出密钥变更，密钥正文隐藏。[认证与换钥](../../../docs/architecture-contract/tcp-authentication.md#bgp-配置与操作)

在「路由宣告…」添加本机 IPv4 或 IPv6 网段。可选择重分发直连网段或填写其他协议编号，例如静态路由 `4`、OSPF `188`。实际发布仍受出口策略约束。修改后回到路由设置，通过「审阅…」统一提交。[BGP 路由配置](../../libraries/network-config/README.md#bgp-配置)

### BGP 路由策略

在邻居属性中打开「入口策略…」或「出口策略…」，新增、编辑、删除或上下移动规则。首个满足全部条件的规则生效。都未匹配时执行所选的默认动作。移除策略后，该方向恢复缺省拒绝。入口策略也可设置本地优先值。

条件可使用双栈网段和前缀长度范围、ORIGIN、MED、本地优先值、AS 路径和三类团体。范围可输入单值或两个端点，例如 `10-20`。允许规则可设置下一跳、调整选路属性、改写 AS 路径，并替换、删除或添加团体。勾选替换并留空可清空相应团体集合。

确认后回到路由设置，点击「审阅…」提交。在「BGP 会话 → 查询前缀…」核对入口判定和各邻居的宣告情况。[BGP 策略契约](../../../docs/architecture-contract/bgp.md#入口政策反馈选路与发表)

### 静态路由

在「IP → 路由」或「IPv6 → 路由」维护当前路由域的静态声明。用右侧的「查找」或路由表下拉框缩小列表；点「新建」或双击一条路由打开属性。
填写目的网段、距离和目标路由表。网关可输入 IP 地址、已配置的接口名或 `地址%接口名`，多个网关用逗号隔开；丢弃路由勾选「黑洞」。距离越小越优先。

「应用」直接保存并留在属性窗口，「确定」保存后关闭，「取消」放弃尚未保存的输入。已有条目可在列表工具栏或属性窗口删除。
可用列表上的「启用」「停用」直接提交，或在属性中切换「已启用」后保存。标志 X 表示停用。停用会撤回路由，保留网关、距离和路由表供重新启用。
需要 root 或 `netdev` 权限。配置已被其他操作更新时，重新从列表打开属性再提交。「路由 → 路由表」显示实际生效路径。

需要同时调整备选表和选路规则，或指定下一跳权重、不可达及禁止动作时，仍在「路由 → 路由域与选路」调整草稿并统一审阅提交。

### 备选表与选路规则

在「路由设置」点击「新建表…」并输入表号，再在新表中添加静态路由。系统保留表号 253–255。「删除表」同时删除表中的路由，已有规则引用时需先调整规则。

打开「选路规则…」新增、编辑或删除规则。选择本机或转发流量，填写源网段和目标表。转发可指定入接口，两种流量均可按报文标记匹配。标记和掩码支持十进制或 `0x` 前缀的十六进制，标记留空时匹配任意值。
数字较小的优先级先匹配。点击「返回」后可继续编辑，再一次审阅和提交路由表、静态路由及选路规则。[查询生效规则和实际路径](../../../docs/architecture-contract/ip-forwarding.md#策略选路)

### 路由准入

在「路由设置」选定路由域，打开「路由准入…」。可按来源协议、IPv4 或 IPv6 目的网段及前缀长度范围新增规则、编辑、删除与调整顺序。协议号和网段留空时匹配任意值。首条命中的规则决定是否允许，允许时可指定优先级与度量。

在「未匹配时」指定默认处理。点击「确定」后回到路由设置，使用「审阅…」一并提交。可回到该域的「路由表」查看生效结果。[路由准入契约](../../../docs/architecture-contract/router-configuration.md#路由准入策略)

### 路由接口与双栈转发

在「路由设置」打开「路由接口…」。列表同时显示当前网卡和已保存的配置，未连接的设备仍可修改。
选中网卡打开「属性…」，可以设定显示名称、管理状态、MTU 和默认路由优先级。首次为当前网卡保存属性时按 MAC 绑定，重启后也可识别。

「IPv4…」可选择沿用系统默认、DHCP 或手动设置，并填写地址、前缀、网关、DNS 和连接后缀。「IPv6…」可添加多个静态地址，逐个指定是否安装直连前缀，并选择何时接受上联路由通告。网桥端口的三层地址在对应的 VLAN 网关设置。
具名域的「IPv4…」可选择 DHCP、手动设置或不配置 IPv4 地址。DHCP 只为所选域安装地址和默认路由。

列表上方可独立启停 IPv4 与 IPv6 转发，影响接口间经过的流量。返回后点击「审阅…」，可将接口、转发开关、静态路由和选路规则一并提交。[转发语义](../../../docs/architecture-contract/router-configuration.md#双栈转发开关)

### 地址分发与 DNS

在「路由设置」打开「地址分发与 DNS…」，选择物理下游接口或已有 VLAN 网关。
选定具名路由域后，同一入口提供本域物理接口及 VLAN 网关的 DHCPv4 地址池、IPv6 通告、下游前缀委派和 DNS 转发设置。用 `ipconfig /domain lab /leases lan10` 查询该域 VLAN 网关的 DHCPv4 下游租约。

- 「DHCPv4…」设置分发范围、客户端网关和 DNS、租期以及分配前的冲突检查。接口须有静态 IPv4。用 `ipconfig /leases <接口名>` 查看当前租约。[地址池要求](../../libraries/network-config/README.md#dhcpv4-地址池)
- 「IPv6 通告…」设置通告间隔、默认网关寿命和客户端 DNS。静态直连 `/64` 与上联委派到该接口的前缀可同时通告。网关寿命填 0 时，客户端不会从该通告取得默认网关。[下游路由通告](../../../docs/architecture-contract/ipv6-link.md#下游路由通告)
- 「IPv6 前缀委派…」选择物理上联，填写稳定的 DUID MAC 与 IAID，为已启用通告的下游分配不同子网编号。可信上联可启用认证重配置。系统须开启 IPv6 转发，上联须有 IPv6 默认路径。[委派要求](../../libraries/network-config/README.md#dhcpv6-前缀委派)
- 「DNS 设置…」可在所选域启用下游转发与缓存。监听地址从本域已配置的静态地址中选择。上游可调整顺序，链路本地 IPv6 上游须指定本域接口。主后缀和搜索域在默认域设置。
  将监听地址填入下游 DHCPv4 或 IPv6 通告的 DNS 列表，客户端即可使用该解析器。[DNS 转发](../../../docs/architecture-contract/dns-forwarding.md)

返回「路由设置」后统一审阅和提交。启用地址分发或通告前，请确认选中了实际承载下游设备的接口。

### 网桥与 VLAN

从左侧打开「网桥」，在顶部选择路由域。窗口的三个页签显示该域已保存的配置，可用工具栏刷新。双击一行打开属性，「新建」和「删除」作用于当前页签。

- **网桥**显示协议模式、优先级、端口数和网关数。新建时通过「物理端口…」添加第一个成员，默认域可直接选择当前网卡。网卡加入前会提示确认，因为现有管理连接可能中断。
- **端口**显示所属网桥、PVID、隔离及生成树参数。PVID 可留空以拒绝无标签和优先级标签入口。带标签与去标签出口可填写 VLAN 范围，例如 `10 20-24`。
- **VLAN**按网桥和 VID 汇总两类成员。打开属性后可选中一组成员，按 Ctrl 选择多个接口。每个接口只能加入一组。选中 VLAN 后可从右侧「三层网关…」设置接口名称及静态 IPv4、IPv6。

每次修改都经审阅提交，成功后刷新三个页签。需要同时调整网关引用、路由或地址分发时，可在「路由设置 → 网桥与 VLAN…」用同一草稿修改并提交。[网桥语义](../../../docs/architecture-contract/switching.md)

### 防火墙与 NAT

在「路由设置」打开「防火墙与 NAT…」。选中预路由入口或子链后打开「规则…」，可以新增、编辑、删除或移动规则。新增规则插在选中项之后，未选中时追加到末尾。规则按显示顺序执行。

规则可按入接口、双栈源网段、目的网段或目的地址集、连接状态以及 TCP 或 UDP 的目的端口匹配。可放行、丢弃、设置路由标记、跳转到子链或返回。
「目的地址集…」按行录入网段。删除地址集或子链前，先移除相关规则的引用。

NAT 可设置固定目的或源地址，也可使用实际出口地址。目的转换可同时配置源转换。改写端口时须在规则中指定 TCP 或 UDP。端口留空时保留原端口，自动源地址转换会处理源端口冲突。
可选择让已有转发连接沿用修改前的规则。返回后统一审阅提交，在「IP → 防火墙」查看生效规则和命中统计。[规则与连接行为](../../../docs/architecture-contract/ip-forwarding.md#预路由规则)

## 接口流量

「接口」表格列出接口的管理状态。选中物理网卡后双击或回车，在工作区打开「接口 > 名称」属性窗口：「常规」页设置管理状态、显示名称、MTU 和默认网关优先级与度量，「流量」页是打开时的累计计数，右侧「动作」打开 IPv4、IPv6 设置。
「应用」立即提交并重新读取，「确定」提交后关闭窗口，「取消」或关闭按钮放弃未提交的修改。打开窗口后若配置被他人修改，提交会被拒绝，请关闭后重新打开。
工具栏的「启用」「停用」立即提交管理状态，保留原地址策略；「新建」打开网桥与 VLAN 设置。观察窗口随后显示实际状态。
root 和 `netdev` 成员可提交。停用当前管理连接经过的网卡会中断该连接。VLAN 网关及网桥端口的转发设置从「网桥」进入。

打开「接口流量」，查看所选路由域各接口的接收和发送速率、累计流量以及丢包数。选中接口可看累计报文、字节数和收发错误。首次读取、刚出现的接口或计数重置后，速率显示为「—」，等下次采样后更新。

root、`netdev` 或 `netview` 成员可查看。每页最多 64 个接口，离开该页停止观察。如观察中断，点击「刷新」恢复。物理接口、VLAN 和回环各自显示计数，同一流量可能经过多个接口。

### 实时流量分析

在「接口流量」选中接口，点击「流量分析…」。窗口按秒刷新主要流量的收发方向、协议、源、目的、速率和字节占比，下方保留最近 10 次采样。
「≥」表示当前统计能确认的下界。「其他或未确定」包括未列出的流量和未能精确归属的字节。采集丢包数单独显示，出现丢包时该窗只统计实际读取到的流量。
本地 root 和 `netdev` 成员可使用。关闭窗口即停止采集。

### 抓包

在「接口流量」选中接口，点击「抓包…」并选择新的 `.pcap` 文件。抓包绑定启动时所选域和接口，切换到其他页面或域后可继续操作。点击「停止抓包」会保存已抓到的报文并显示抓包缓冲丢弃数。接口移除、满 60 秒或达到 64 MiB 时会自动停止保存。

本地 root 和 `netdev` 成员可抓取该接口收发的报文。保存的文件可用 Wireshark 或 `tcpdump -r` 打开。启用网卡发送校验和卸载时，文件中的部分发送报文可能显示未完成的校验和。
