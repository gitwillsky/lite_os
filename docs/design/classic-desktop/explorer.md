# 资源管理器

`file-explorer` 是唯一的文件夹浏览程序，"我的电脑""我的文档""回收站""控制面板"都是它的位置。
它使用普通 Wayland 连接，没有外壳权限；命令行参数是路径或虚拟位置 `::my-computer`、`::control-panel`。

## 位置

1. 目录：真实文件系统目录。`$HOME` 显示为"我的文档"，`$HOME/.local/share/Trash/files` 显示为"回收站"，
   它们仍是普通目录，只借用名称与图标；根目录显示为"本地磁盘"。
2. 我的电脑：由 `/proc/mounts` 中的磁盘类文件系统生成"本地磁盘 (挂载点)"与"CD 驱动器 (挂载点)"，另有"控制面板"。
   没有软盘与网络驱动器后端，不列出。
3. 控制面板：列出 `/usr/share/applications` 里 `Categories` 含 `Settings` 的桌面条目，双击启动；目前有"系统"与"日期/时间"两个（`control-panel` 程序，只读信息页）。这些条目不出现在开始菜单的程序里。
4. "向上"：目录到父目录，根目录到"我的电脑"，控制面板到"我的电脑"。

## 窗口布局（逻辑像素，自上而下）

1. 菜单栏高 20：文件、编辑、查看、收藏、工具、帮助。下拉菜单中没有对应功能的项保持灰色
   （编辑的剪切/复制/粘贴、收藏的"(空)"、工具、帮助）。
2. 工具栏（可由"查看"菜单隐藏）：后退、前进、向上、搜索、文件夹、历史、移至、复制到、删除、撤消、查看。
   前六个带文字标签。位图来自 `browseui.dll` 的 47 帧横条（默认、悬停、禁用三条），每帧 20 × 20，洋红为透明色。
   当前只有后退、前进、向上、文件夹和查看可用，其余以禁用位图绘制。
3. 地址栏：地址标签、带位置图标的编辑框、下拉箭头与"转到"。回车或"转到"解析绝对路径、相对当前目录的路径、
   "我的电脑"/"控制面板"；找不到时在状态栏提示而不跳转。
4. 左侧面板宽 190（窗口窄于 420 时不显示）：默认是信息面板（位置名称、选中项类型/大小/修改日期）；
   "文件夹"开启后是树，根为"我的电脑"，当前位置的祖先自动展开，展开框、滚动条与关闭按钮可用。
5. 文件列表：大图标、小图标、列表、详细资料四种查看方式。详细资料有名称、大小、类型、修改时间四列，
   大小以 KB 向上取整，时间按 UTC 显示为 `年-月-日 时:分`（系统没有时区数据库）。
6. 状态栏三格：对象数或选中数、选中文件大小、"我的电脑"区域标签。

## 交互

1. 单击选择，双击或 Enter 打开：文件夹就地导航，可执行文件启动，其余文件提示没有关联程序。
2. 方向键、Home、End、PageUp/PageDown 移动选择；输入字符跳到下一个同首字母的项；Backspace 与 Alt+Up 向上；
   Alt+Left/Right 后退/前进；F5 刷新；F4 或 Ctrl+L 聚焦地址栏。
3. 窗口标题与任务栏标题随位置变化。

## 文件操作

1. 删除（Del、菜单、工具栏、右键）先弹确认框，确认后移入回收站：freedesktop Trash 布局，`Trash/files` 存内容，
   `Trash/info/<名>.trashinfo` 记原路径与时间；重名自动加序号。在回收站里删除是永久删除，措辞不同。
2. 回收站里可"还原"（原位置被占用时改名不覆盖）与"清空回收站"（有确认）。
3. 剪切/复制/粘贴只在本进程内有效（没有跨应用剪贴板）；复制重名得到"X 的副本"，不能把文件夹复制/移动进自己内部。
4. 重命名（F2、菜单、右键）与"新建文件夹"在列表里原地编辑；名称为空、含 `/` 或已存在时拒绝并在状态栏说明。
5. 右键：项目上是打开/剪切/复制/删除/重命名，空白处是粘贴/新建文件夹/刷新。确认框是窗口内的模态覆盖层，不是独立窗口。

## 范围缩减

1. 不支持多选与拖放；"移至""复制到"与"撤消"按钮保持禁用。
2. 不预览文件内容；此前的 64 KiB 文本预览已移除，文本需要时由将来的关联程序打开。
3. 不显示驱动器容量：内核尚未向用户态提供 `statfs` 的封装。
