# 桌面外壳

`desktop` 进程独占本文件描述的外壳：桌面图标层、任务栏、开始菜单、托盘与系统对话框。
窗口叠放、焦点、移动与 Alt+Tab 属于 `compositor`（见 [interaction.md](interaction.md)）。
中文文案逐字内容均为**待核**，结构与行为的置信度逐项标注。

## 进程边界

按 Windows 2000 的实现划分程序：外壳（`desktop`）只含桌面、任务栏、开始菜单、托盘与运行对话框；
任务管理器（`taskmgr`）、音量控制（`sndvol`）、日期/时间与系统属性、"关于"（`control-panel`）、资源管理器（`file-explorer`）
都是独立程序，外壳只负责启动它们。窗口列表与控制走标准 foreign-toplevel，对同一桌面的程序开放。这些程序共享 `/usr/lib/liteos/` 里的系统共享库（见用户态架构），不各自内嵌 `classic-ui` 等基础库。

## 桌面

1. 背景色 `COLOR_BACKGROUND`（`#3A6EA5`），默认无壁纸；壁纸支持"居中 / 平铺 / 拉伸"三种方式（确定）。
2. 默认图标（自上而下排在左列，网格 75 × 75，待核）：

   | 图标 | 打开 | 说明 |
   |---|---|---|
   | 我的文档 | `file-explorer` 定位到用户主目录 | |
   | 我的电脑 | `file-explorer` 的"我的电脑"视图 | 列出各磁盘（挂载点）与"控制面板" |
   | 回收站 | `file-explorer` 的回收站视图 | 空/满两种图标 |
   | 红色警戒 2 | Wine 启动游戏 | 用户放入游戏文件后由 `.desktop` 条目生成 |

   Windows 2000 默认还有"网上邻居""Internet Explorer""连接到 Internet"。LiteOS 没有对应后端，**不提供**
   （范围决策，记录于此）。
3. 图标外观：32 × 32 图标，下方居中标题文字（白色，带 1 像素黑色阴影以保证在任意壁纸上可读，待核：
   Windows 2000 在纯色背景下是图标标题背景取桌面色、文字白色、无阴影）。选中时图标叠加 50% `HIGHLIGHT`
   色调，标题背景变为 `HIGHLIGHT`、文字 `HIGHLIGHTTEXT`；获得焦点时标题外加点状虚线框。
4. 图标标题最多两行，超出以"..."截断；选中时展开显示全文（确定）。
5. 右键空白处菜单：
   - "排列图标(I)" ▸ "按名称(N)""按类型(T)""按大小(S)""按日期(D)"、分隔线、"自动排列(A)"
   - "对齐图标(E)"
   - 分隔线
   - "刷新(E)"
   - 分隔线
   - "粘贴(P)""粘贴快捷方式(S)"
   - 分隔线
   - "新建(W)" ▸ "文件夹(F)""快捷方式(S)"、分隔线、"文本文档"
   - 分隔线
   - "属性(R)"（打开"显示 属性"）
6. 图标可拖动；未开"自动排列"时自由放置并吸附网格，位置按用户持久化。

## 任务栏

1. 默认停靠屏幕底部，高 28，面色 `BTNFACE`，顶边 `BDR_RAISEDINNER`（待核）。
2. 从左到右：
   1. "开始"按钮：16 × 16 的 LiteOS logo（取代 Windows 旗帜）+ 粗体文字"开始"；按下（开始菜单打开时）显示按下状态。
   2. 竖向分隔条（`EDGE_ETCHED` 竖线加一道可拖动握把）。
   3. 快速启动工具栏：16 × 16 图标按钮，默认"显示桌面""我的文档"（待核：Windows 2000 默认是显示桌面、
      Internet Explorer、Outlook Express；后两者不提供）。按钮悬停显示单层凸起边框。
   4. 竖向分隔条。
   5. 任务按钮区：每个顶层窗口一个按钮，16 × 16 图标 + 标题，宽度均分剩余空间，最大 160；
      活动窗口的按钮显示为按下状态，并以 `BTNHIGHLIGHT`/`BTNFACE` 棋盘格填充（确定）；
      窗口请求注意时按钮闪烁 `HIGHLIGHT` 色（确定）。按钮过多时出现上下翻页箭头（不分组，Windows 2000 无分组）。
   6. 通知区（托盘）：`BDR_SUNKENOUTER` 凹边，内含 16 × 16 图标与时钟。
3. 任务按钮行为：单击未激活窗口的按钮 → 激活并还原；单击已激活窗口的按钮 → 最小化（确定）；
   右键 → 该窗口的系统菜单（还原、移动、大小、最小化、最大化、关闭）。
4. 右键任务栏空白处："工具栏(T)" ▸、分隔线、"层叠窗口(S)""横向平铺窗口(H)""纵向平铺窗口(E)""最小化所有窗口(M)"、
   分隔线、"任务管理器(K)"、分隔线、"属性(R)"。
5. 任务栏属性："总在最前(T)""自动隐藏(U)""在开始菜单中显示小图标(S)""显示时钟(C)""使用个性化菜单(P)"（确定）。

## 托盘

1. 时钟：显示 `H:mm`（24 小时制，中文区域默认，待核）；悬停工具提示显示完整日期"yyyy年M月d日"；
   双击打开"日期/时间 属性"。
2. 音量：喇叭图标（静音时带红色禁止标记）；单击弹出音量滑块小窗（竖向滑块 + "静音"复选框）；
   双击打开"音量控制"。音量与静音直接读写 ALSA control（`Master Playback Volume/Switch`）。
3. 输入法指示器：显示当前输入法（"En"/中文输入法图标），单击弹出输入法列表（待核：Windows 2000 的语言栏
   位于托盘左侧）。
4. 托盘图标的气球提示：圆角黄色气泡（`INFOBK`）带标题与关闭按钮，指向图标（确定：气球提示是 Windows 2000 引入的）。

## 开始菜单

1. 弹出于"开始"按钮正上方，外框 `EDGE_RAISED`。左侧是竖向侧栏位图 `start-banner`（21 × 233）：背景上黑下蓝的
   竖向渐变，白色文字自下而上竖排"LiteOS 2000 Professional"，"2000"为细体；位图靠底部对齐（原版实测，确定）。
2. 菜单项使用 32 × 32 大图标（"在开始菜单中显示小图标"打开后为 16 × 16），项高 32 + 上下各 2（待核）。
3. 菜单项（自上而下）：
   - "Windows Update"在 LiteOS 中**不提供**；顶部直接是程序组。
   - "程序(P)" ▸：按 `/usr/share/applications/*.desktop` 的 `Categories` 生成子菜单；"附件"下包含
     "命令提示符""记事本（若有）""系统工具" ▸ "任务管理器"等。
   - "文档(D)" ▸：最近打开的 15 个文档；底部"我的文档"。
   - "设置(S)" ▸："控制面板(C)""任务栏和「开始」菜单(T)..."。
   - "搜索(C)" ▸："文件或文件夹(F)..."。
   - "帮助(H)"
   - "运行(R)..."
   - 分隔线
   - "关机(U)..."
4. 子菜单使用 16 × 16 小图标，向右展开；悬停约 400 毫秒自动展开（`MenuShowDelay`=400，确定）。
5. 个性化菜单：长期未使用的程序项被折叠，底部出现双箭头"»"项；悬停片刻或单击后展开，被展开的项以较浅的
   背景色显示（确定：Windows 2000 引入的"个性化菜单"）。
6. 子菜单中的项可拖动重排、右键有"打开""删除""重命名""属性"等（确定）。

## 运行

"运行"对话框：左侧 `run` 图标 32 × 32，文字"请键入程序、文件夹、文档或 Internet 资源的名称，LiteOS 将为您打开它。"；
"打开(O):"组合框，带最近记录下拉；按钮"确定""取消""浏览(B)..."。命令行以当前用户身份执行。

## 系统对话框外观通则

1. 对话框背景 `BTNFACE`，外框 3 像素（见 [appearance.md](appearance.md)），标题栏只有关闭按钮（以及"?"帮助按钮，当有帮助时）。
2. 按钮默认大小 75 × 23，按钮之间间距 6，与对话框边缘间距 7（对话框单位换算后的典型值，待核）。
3. 消息框：左侧 32 × 32 图标（错误、警告、信息、问题四种），右侧文字，下方居中按钮；弹出时播放对应系统声音
   （声音素材见 [assets.md](assets.md)）。
