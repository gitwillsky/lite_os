# desktop-settings

- **类型**：库
- **作用**：每用户的任务栏选项、桌面背景、文件夹查看方式和详细资料列
- **产物 / 安装位置**：共享库 `libdesktop_settings.so`
- **对应的 Windows 2000 组件**：注册表 `HKCU\Control Panel\Desktop` 与任务栏设置
- **依赖**：liteos-runtime

`$HOME/.config/liteos/desktop.conf` 由控制面板和资源管理器分别更新各自的字段，桌面外壳按修改时间发现变化后应用。
文件是仅用户可读写的 `键=值` 文本，缺失或损坏的项用默认值，不会阻止外壳启动。
文件夹查看方式保留最近设置的 512 个非默认位置，以规范目录的文件 URI 或固定的外壳位置标识区分。
详细资料列使用同样的位置标识，保存最近 512 个自定义布局的列顺序、宽度和可见性。
网络通知图标按接口名记录用户隐藏的连接。连接属性单独保存此偏好，当前生效的网络配置仍由 router-config 持有。
