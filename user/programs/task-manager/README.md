# task-manager

- **类型**：程序（可执行文件）
- **作用**：任务管理器
- **产物 / 安装位置**：`/bin/taskmgr`
- **对应的 Windows 2000 组件**：taskmgr.exe
- **依赖**：classic-ui、classic-theme、canvas、typeface

沿用 Windows 2000 的菜单栏（文件、查看、窗口、帮助；"窗口"只在应用程序页出现）、三格状态栏，并增加独立 GPU 标签。

- 应用程序：foreign-toplevel 窗口列表，结束任务、切换至、新任务（以当前用户执行命令）。
- 进程：读 procfs，映像名称、PID、CPU、CPU 时间、内存使用，点列标题排序，含合成的 System Idle Process，结束进程。
- 性能：CPU 总使用率、按实际逻辑 CPU 编号分别采样的历史曲线；查看 > CPU 使用记录可切换“所有 CPU 使用一个图表/每个 CPU 使用一个图表”（默认后者），多图按使每张图较短边最大的行列自动排布，网格随采样与曲线同步左移；内存数字表、仪表和历史曲线，句柄/线程/进程总数、物理内存、认可用量、内核内存。
- GPU：仿性能页的“设备/总数”统计分组与整行选择的客户端列表；按 DRM client-id 去重，列出缓冲占用与标准 `drm-shared-memory` 共享量，点列标题排序；私有缓冲合计只累加各客户端的非共享部分；与 CPU 采样共用后台刷新周期。跨客户端共享资源不能求和当作显存；未提供的指标隐藏，不显示占位或推测值。
- 内存展示：进程列、性能页、仪表和状态栏共用二进制单位，按数值自动选择 KiB、MiB、GiB 及以上单位；KiB 保留整数，其余保留一位小数，舍入到 1024 时提升单位。采样和排序始终使用原始 KiB 数值。
- 查看菜单的更新速度（高 0.5 秒、正常 2 秒、低 4 秒、暂停）控制采样间隔。

没有的：选项菜单（总在最前、最小化时隐藏需要窗口层协议）、选择列、显示内核时间（内核没有分开的内核/用户时间统计）、层叠/平铺。
