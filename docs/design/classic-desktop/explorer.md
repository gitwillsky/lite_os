# 资源管理器

`file-explorer` 是唯一的文件夹浏览程序，“桌面”“我的电脑”“我的文档”“回收站”“控制面板”“网上邻居”
“网络和拨号连接”都是它的位置。它使用普通 Wayland 连接，没有外壳权限；命令行参数是路径或虚拟位置
`::desktop`、`::my-computer`、`::control-panel`、`::network-places`、`::entire-network`、`::network-connections`。
样式、文案与交互以 Windows 2000 SP4 简中原版为准：菜单取 `browselc.dll` 266 合并 `shell32.dll` 210/215/216/221，
列名取 shell32 8976–8986、9386–9389 与 netshell 1000–1004，Web 视图取 `webvw.dll` 模板与字符串 5001–5061。

## 位置与命名空间

1. 桌面是根：我的文档（`$HOME`）、我的电脑、网上邻居、回收站（`trash_files`，遵循 `XDG_DATA_HOME`），再加 `~/Desktop` 的内容。
2. 我的电脑：`/proc/mounts` 中的磁盘类文件系统生成“本地磁盘 (挂载点)”“光盘 (挂载点)”（shell32 9397/9399），容量由 statvfs 读取；
   另有“控制面板”（系统文件夹）。没有软盘与网络驱动器后端，不列出。
3. 控制面板：`/usr/share/applications` 中 `Categories` 含 `Settings` 的桌面条目，备注取 `Comment[zh_CN]`。
   `Exec` 为 `file-explorer ::位置` 的条目是外壳文件夹，在当前窗口打开（“网络和拨号连接”）。
4. 网上邻居：只有“整个网络”（空文件夹）；系统没有 SMB 与邻居发现，“添加网上邻居”“邻近的计算机”不生成。
5. 网络和拨号连接：`/sys/class/net` 中 `type` 为 1 的接口按 ifindex 命名“本地连接”“本地连接 2”……，
   类型 LAN，状态取 IFF_UP 与 carrier（已启用 / 网络电缆被拔出 / 禁用），设备名取驱动名，所有者“系统”；
   打开即 `control-panel network <接口>`。没有拨号/VPN，“新建连接”向导不生成。
6. 回收站：列出 `.trashinfo` 的原名称、原位置与删除日期（`DeletionDate` 为本地时间）；回收站内的文件夹不可进入。
7. “向上”：我的电脑、网上邻居、我的文档、回收站到桌面；根目录到我的电脑；控制面板到我的电脑；
   网络和拨号连接到控制面板；整个网络到网上邻居。

## 详细资料列

| 位置 | 列 |
| --- | --- |
| 目录、桌面 | 名称、大小、类型、修改时间 |
| 我的电脑 | 名称、类型、大小（总容量）、可用空间 |
| 控制面板、网上邻居、整个网络 | 名称、备注 |
| 回收站 | 名称、原位置、删除日期、类型、大小 |
| 网络和拨号连接 | 名称、类型、状态、设备名、所有者 |

文件大小按 `StrFormatKBSize`（KB 向上取整、千分位）；容量与 Web 视图大小按 `StrFormatByteSize`（三位有效数字、截断，
单位取 shlwapi 259–265）；时间按 `/etc/localtime` 显示为 `年-月-日 时:分`。大小列右对齐；数值与日期列首次单击降序。
切换到没有当前排序列的位置时回到按名称升序。

## 窗口布局

1. ReBar 三行带区，每行有把手与蚀刻边线，第一行右端是品牌 logo（读取期间转动）：
   菜单栏；标准按钮；地址栏（“地址(D)”、带位置图标与层次下拉的 ComboBoxEx、“转到”按钮）。
   “查看 → 工具栏”分别隐藏标准按钮与地址栏。
2. 标准按钮：后退▾ 前进▾ 向上 ┃ 搜索 文件夹 历史 ┃ 移至 复制到 删除 撤消 ┃ 查看▾；后退、搜索、文件夹、历史带文字，
   其余靠工具提示。位图为 browseui 外壳条与 IE 条（冷/热/禁用）。后退/前进的箭头列出最多 9 个历史位置。
3. 地址下拉：桌面、桌面下各项、我的电脑下的驱动器与控制面板，加当前位置的祖先链；选中即导航，Enter 解析
   绝对路径、相对当前目录的路径或虚拟文件夹显示名。
4. “文件夹”浏览栏（宽 200）：标题“文件夹”与关闭按钮，下方为以桌面为根的命名空间树，按需读取分支。
5. Web 视图面板（宽 200，白底加 `wvleft.bmp` 水印）：32 像素位置图标（左 12、上 11）、14 磅菜单字体粗体标题、
   `wvline.gif` 分隔线、左缩进 12 的正文。客户区宽度小于 400 时隐藏。正文按位置：
   - 我的电脑/目录（folder.htt）：选定提示或选中项说明（名称、类型、修改时间、大小、属性；驱动器为总计、
     带色块的已用/可用空间与三维饼图，已用蓝、可用品红）；多选为“N 个选定的项目。”与总计文件大小；“另请参阅:”链接。
   - 控制面板（controlp.htt）：介绍、选中项名称与备注。
   - 回收站（recycle.htt）：介绍，“清空回收站”“全部恢复”按钮或“回收站中没有项目。”，选中时“还原”按钮。
   - 网上邻居（nethood.htt）：介绍与“网络和拨号连接”链接、“另请参阅: 我的文档、我的电脑”。
   - 网络和拨号连接（dialup.htt）：介绍与选中连接的类型、状态、设备名。
6. 列表视图：大图标、小图标、列表、详细资料；所有位置默认大图标，本窗口内记住每个位置最后的查看方式。
   选中外观按 comctl32：只高亮名称标签、图标与高亮色混合，详细资料不整行选择（共享列表项绘制，见 UI 架构）。
7. 状态栏三格：对象数（“N 个对象”“N 个对象(可用磁盘空间: X)”“选定 N 个对象”），选中或全部文件大小，
   带图标的“我的电脑”区域格；右下角尺寸手柄可拖动缩放窗口（最大化时不显示）。

## 菜单

- 文件：无选择时“新建 → 文件夹 / 快捷方式 / 文本文档”；有选择时粗体“打开”、“发送到 → 我的文档”（回收站为“还原”）；
  回收站有“清空回收站”；创建快捷方式、删除、重命名、属性、关闭。
- 编辑：撤消、剪切、复制、粘贴、粘贴快捷方式、复制到文件夹…、移动到文件夹…、全部选定、反向选择。
- 查看：工具栏 ▸、状态栏、浏览栏 ▸（文件夹）、四种查看方式、排列图标 ▸（按当前位置的列）、对齐图标、
  选择列…、自定义文件夹…、转到 ▸（后退、前进、向上一级、主页与历史记录）、刷新。
- 收藏、工具、帮助：结构同原版，“关于 Windows”打开 `control-panel winver`。
- 右键：项目上为打开/发送到/剪切/复制/创建快捷方式/删除/重命名/属性（回收站项为还原/剪切/删除/属性）；
  空白处为查看 ▸、排列图标 ▸、对齐图标、刷新、自定义文件夹、粘贴、粘贴快捷方式、撤消、新建 ▸、属性。

## 文件操作

1. 删除先确认（shell32 67/68 措辞），移入 freedesktop Trash；回收站内删除是永久删除。
2. 还原/全部恢复回到原位置，原位置被占用时改名不覆盖；清空回收站有确认。
3. 剪切/复制/粘贴在本进程内有效；“复制到/移动到文件夹”用“浏览文件夹”对话框（模态，以桌面为根的命名空间树，
   只有真实目录可确定）。复制重名得到“X 的副本”，不能把文件夹复制或移动进自己内部。
4. 重命名、新建文件夹与新建文本文档在列表里原地编辑。

## 键盘

Enter 打开，Alt+Enter 属性，Backspace 向上，Alt+←/→ 后退/前进，F2 重命名，F5 刷新，Del 删除，
Ctrl+X/C/V/A，Alt+D 或 F4 转到地址栏（地址栏内 F4 展开下拉）。

## 范围缩减

1. 没有 `.lnk` 外壳链接、撤消日志、搜索助理、收藏夹与历史记录存储、文件夹选项与自定义文件夹对话框：
   对应菜单项与按钮保留原位并禁用。“链接”工具栏不提供。
2. 没有浏览器：模板中指向 microsoft.com 的链接（Windows Update、支持）不生成。
3. Web 视图面板内容超出窗口高度时裁剪，不出现滚动条；链接没有 `title` 悬停提示；浏览栏宽度固定，没有分隔条拖动。
4. 查看方式只在本窗口生命周期内记忆，不写入磁盘。
