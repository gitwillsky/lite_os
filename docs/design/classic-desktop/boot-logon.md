# 开机、登录、注销与关机

画面序列与文案按简体中文 Windows 2000 Professional 还原，品牌按 [README.md](README.md) 替换。
每个画面写明由哪个组件绘制，产品会话与权限边界见[桌面验证](../../development/desktop-verification.md)。
本文件所有中文文案的逐字内容均为**待核**（来自记忆与截图描述），画面结构与按钮集合为确定。

## 画面序列

| # | 画面 | Windows 2000 对应阶段 | LiteOS 阶段 | 绘制者 |
|---|---|---|---|---|
| 1 | 启动画面 | 内核初始化、服务启动 | kernel 起，init / `rcS` / 服务期间由 compositor 接续 | `kernel boot_screen`，随后 `compositor boot.rs` |
| 2 | 欢迎使用（Ctrl+Alt+Del） | Winlogon 等待安全注意序列 | 会话开始 | `logon` |
| 3 | 登录到 LiteOS | GINA 登录对话框 | 认证 | `logon` |
| 4 | 正在加载您的个人设置 | 加载用户配置 | 拉起 `desktop` | `logon` |
| 5 | 桌面 | Explorer 外壳 | `desktop` 首帧 | `desktop` |

画面之间的切换：内核到 compositor 无闪烁接续（compositor 接管 scanout 时先画与内核最后一帧逐像素相同的内容）；
1 → 2 允许一次全黑帧（Windows 2000 在此处同样黑屏一下，待核）；2 之后全部在桌面背景色上进行。

## 1. 启动画面（kernel 起，compositor 接续）

整个启动阶段只有**一张** 640 × 480 的整幅位图（原版的 `ntoskrnl.exe` 位图 1），内核从 GPU 初始化后的第一刻起就把它画上屏幕，
compositor 随后接着画同一张图。这取代了早先设想的"NTLDR 文本进度条 + 另一张启动画面"两段式（置信度：几何为实测确定；
原版在 VGA 模式下由 NTLDR 先显示一屏文本，本系统没有这一屏，直接从位图开始，是有意的简化）。

位图几何（位图坐标，左上角 (0, 0)，区间含两端；原版实测）：

| 区域 | 坐标 | 内容 |
|---|---|---|
| 上部 | y 0 到 419 | 白色背景，居中放产品标志与名称，右上角品牌字标 |
| 分隔带 | y 420 到 425 | 6 像素高的蓝色渐变，主色 `#00299C` |
| 底栏 | y 426 到 479 | 纯色 `#C0C0C0` |
| "正在启动..." | 左边缘 x 203，y 436 到 445 | 黑色 12 像素宋体风格文字，**烘焙在位图里** |
| 进度槽外框 | x 273 到 437，y 436 到 445（165 × 10） | 1 像素凹边：上、左 `#808080`，下、右 `#FFFFFF` |
| 进度槽内部 | x 274 到 436，y 437 到 444（163 × 8） | 位图里是空的 `#C0C0C0`，进度由程序涂成 `#00299C` |
| 版权行 | y 458 到 468，水平居中 | 黑色小字，烘焙在位图里 |

槽内部矩形与填充色写在 `LBS1` 文件头里，内核与 compositor 都从头部读取，不在代码里各存一份。

屏幕上的摆放：取最大的整数放大倍数 `scale = min(宽 / 640, 高 / 480)`（向下取整，至少为 1），居中，其余区域纯黑；屏幕小于
640 × 480 时不显示。3008 × 1692 得到 scale 3（1920 × 1440，左右各留 544、上下各留 126）；1504 × 846 得到 scale 1。
内核与 compositor 共用 `boot-scene` crate 计算这些，所以接管瞬间画面逐像素一致。

进度条按千分比从左向右增长，只增不减，每次只重画新增部分。内核阶段的里程碑：

| 里程碑 | 进度 |
|---|---|
| 画面上屏（内存与 GPU 就绪） | 0 ‰ |
| 命名空间与 IPC/socket 就绪 | 100 ‰ |
| 文件系统与 scheduler 就绪 | 200 ‰ |
| 平台设备与块设备发布完成 | 300 ‰ |
| 音频初始化完成（DRM 接管前内核的最后一步） | 400 ‰（`KERNEL_PROGRESS_PERMILLE`） |

DRM 绑定 completion work 之后内核不能再同步刷新，所以内核阶段到此为止。compositor 以 400 ‰ 画出同一张图，
保证接管时进度条不倒退、不跳变。compositor 初始化完成、外壳启动和外壳首帧分别把目标提高到 600、800、1000 ‰，
显示进度按时间平滑追赶已达成的目标；达到 1000 ‰ 后才交接给外壳画面。

原版的进度条是循环滚动的"跑马灯"还是按比例填充，尚未用参照核实（置信度：待核）；目前按比例填充实现，
因为内核没有定时器可用来驱动动画。

## 2. 欢迎使用（logon）

1. 桌面背景色 `#3A6EA5` 全屏，不显示图标与任务栏。
2. 居中对话框，标题"欢迎使用 LiteOS"，无关闭按钮。顶部是 `logon-banner` 横幅位图（产品名与 logo）。
3. 横幅下方左侧是 `ctrl-alt-del` 键盘图标（原版 32 × 32），右侧文字：
   "按 Ctrl-Alt-Delete 开始。"
   "要求按 Ctrl-Alt-Delete 键可以确保在登录时的安全性。有关详细信息，请单击“帮助”。"
4. 底部按钮："帮助"。
5. 仅响应 Ctrl+Alt+Del（由 compositor 作为安全注意序列直接投递给 `logon`，其他进程收不到也无法伪造）。

## 3. 登录到 LiteOS（logon）

1. 对话框标题"登录到 LiteOS"，顶部同样的横幅位图。
2. 字段：
   - "用户名(U):" 文本框，默认填上一次登录的用户名。
   - "密码(P):" 密码框，以 `*` 显示。
3. 按钮："确定"（默认按钮）、"取消"、"关机(S)..."、"选项(O) <<"。
4. "选项(O) <<"折叠时变为"选项(O) >>"，展开后显示"登录到(L):"下拉框（只有本机名一项）与
   "使用拨号网络连接登录(D)"复选框（灰显，本期不提供）。
5. 认证失败：消息框"登录消息"——"系统无法让您登录。请确定您的用户名及域是正确的，然后再次键入密码。
   字母密码必须使用正确的大小写。"，图标为警告，按钮"确定"；关闭后清空密码框并聚焦。
6. 认证依据 `/etc/passwd` 与 `/etc/shadow`；成功后以该用户身份拉起 `desktop`。

## 4. 正在加载您的个人设置（logon）

桌面背景色上居中的小对话框，无标题栏按钮，文字"正在加载您的个人设置..."；`desktop` 首帧送达后关闭。

## 会话内 Ctrl+Alt+Del：LiteOS 安全

1. 桌面变暗（待核：Windows 2000 是切换到独立的安全桌面，背景为桌面色），居中对话框"LiteOS 安全"。
2. 上部"登录信息"分组框："您以 <用户名> 身份登录。"、"登录日期: <日期时间>"。
3. 中部文字："使用任务管理器关闭不响应的应用程序。"
4. 按钮（两行三列）："锁定计算机(K)"、"注销(L)..."、"关机(S)..."、"更改密码(P)..."、"任务管理器(T)"、"取消"。

锁定计算机后显示"计算机已锁定"对话框：说明只有当前用户或管理员可以解锁，"按 Ctrl-Alt-Delete 解锁"；
解锁对话框"解除计算机锁定"要求输入当前用户密码。

## 关闭 LiteOS

由开始菜单"关机(U)..."或 Alt+F4（焦点在桌面时）打开：

1. 对话框"关闭 LiteOS"，顶部横幅位图。
2. 左侧 `shutdown` 图标（32 × 32），右侧"希望计算机做什么(W)?"下拉框：
   - "注销 <用户名>"——"结束会话，保持计算机运行并处于开机状态。"
   - "关机"——"结束会话并关闭 LiteOS，以便您可以安全地关闭电源。"
   - "重新启动"——"结束会话，关闭 LiteOS，然后再次启动 LiteOS。"
   下拉框下方显示所选项的说明文字。
3. 按钮："确定"、"取消"、"帮助"。下拉框默认值为上一次的选择。
4. 确认后依次显示"正在保存您的设置..."、（注销时）回到"欢迎使用"画面；（关机时）kernel 关闭电源。
