# BGP IPv6 下一跳发布契约

本文件拥有 RFC 2545 §3 与 RFC 8950 的 IPv6 下一跳范围、地址资格与变化处理。格式与服务寿命见 [BGP 契约](bgp.md)，地址观察见 [NET 地址契约](ipv6-link.md#地址查询与版本)。
当前已装配原生服务入口，宿主用例覆盖实际生产协议路径；来宾、FRR/BIRD 与规模验收尚未完成。

## 资格与所有权

1. NET 唯一拥有接口、载波、地址及 DAD 状态；AddressSnapshot 同次冻结 usable，避免消费者拼接不同时刻的接口与地址结果。
   BGP 原生 adapter 只投影可用 IPv6 地址为 ExportAddress（实际接口、地址、前缀、on-link）；协议库不接管 NET 类型、配置、计时器或 RPC。
2. RoutingDomain 只保留这一份不可变资格投影；相同输入不分配，非法地址/前缀或 OOM 保留旧投影。
   接口命名、Linux flags、BGP Identifier 和持久接口名均不能充当链路证明。实际 link-local TCP 的范围来自登记该连接时的 SourcePeer。
3. 有出口配置时通过既有 RIB 图通知更新地址，保证新连接首次宣告也用当前资格。仅对协商允许 IPv6 下一跳的活动地址族重算出口。
   观察/来源能力失败沿原域退出清理；这是运行时观察，不提供跨重启状态恢复。

## 发布规则

1. Next-hop-self 默认使用实际 TCP 地址族。IPv4 单播使用 IPv6 下一跳须协商 IPv4 MP，且对端声明 Extended Next Hop 三元组 (1, 1, 2)。
   Link-local TCP 优先选本接口可用的非链路 IPv6 地址，缺少时可用本机其他接口的合格地址，并附带当前链路地址。策略可指定全局下一跳。
   已知地址资格下，默认本机下一跳失去使用资格时拒绝该目标；不能继续使用已经删除、未完成 DAD 或所在接口不可用的本机地址。
2. 接收邻居的共同链路由其实际 TCP 范围，或当前合格 on-link 地址覆盖确定；全局邻居覆盖多个接口时拒绝不明确的范围，不任意选择接口。
   下一跳标识本机时（包括另一接口的本机全局地址），附带接收邻居所在接口的可用链路地址；有多个值时按地址顺序稳定选择。
3. 第三方全局下一跳属于共同子网时，只能保留原始下一跳自身的辅助地址，并核对原始邻居与接收邻居的链路相同。
   不用本机链路地址冒充第三方。已证明应携带辅助地址但缺少合格值时，按 Unsupported 拒绝并撤回旧宣告，可由既有逐目标查询观察；不重启健康会话。
4. 非共同链路只发布全局地址，剥除上游辅助地址。IPv6 下一跳用 16/32 字节 MP_REACH，撤回使用同族 MP_UNREACH。容量与合批按实际长度及编码计算。
   发送等价包含全局及辅助地址；仅辅助地址变化也产生 UPDATE，原始接收、Loc-RIB、来源确认与保留团体边界保持。

## 更新、发送与成本

1. 资格变化给可发送 IPv6 下一跳的地址族登记重算游标，归并实际发送记录与当前学习、本机、重分发目标，包含曾因范围不足而未宣告的网段。
   每次至多推进既有刷新批次，按有序索引定位，不从表头重扫、不一次展开全表；重复变化合并为一轮跟进，不取消部分 TCP 帧。
2. 网络重算只发布实际变化；邻居 Route Refresh 则重发实际已宣告记录，即使属性未变。两种义务共享截止索引与有界积压，远端重发优先，不能被普通去重吞掉。
   MRAI、发送背压、帧完成记账和关闭清理仍归唯一 AdjRibOut；资格恢复可重新发布，失去资格可撤回。
3. 同批前缀共享一份不可变发送投影，包含属性引用、全局/辅助下一跳及方向标量；每条记录只持 Rc，避免百万前缀重复持有相同大标量。
   Rc 仅属单 actor；编码、预留与共享分配均在消费工作前完成，失败保持待办，sent 不分配。最后一个记录/在途帧退出时释放，不增加驻留池或全表缓存。
4. 观察存储为 O(合格地址数)，变化时捕获；每次投影线性扫描该集合。出口游标按索引作有界查找，本机网段资格按有序数组推进；每个实际宣告批次新增一个共享投影，撤回不创建。
   完整全表、规则/地址规模、峰值内存及传播延迟随控制面统一验收；当前依据所有权与有界工作审查，不新增孤立微基准，不把 Clippy 当作性能证据。
   跨族只增加每连接能力标量及按当前宣告编码合批的判断。带接口的安装检查复用冻结邻接并跳过递归工作区，数据面沿已有 IPv6 网关路径。

现有 IPv6 BGP/NET/RIB 用例覆盖实际流量、同链路本机/第三方、链路 TCP 范围、跨链路剥离、辅助地址变化、资格丢失后的撤回与恢复、无变化不发包及属性头容量边界。
既有出口用例保护部分发送、MRAI、重发遍历与跟进合并；地址 codec 用例保护版本、usable 状态及失败拒绝。原生 IPC 竞态、完整互通与规模性能仍待系统验收。
