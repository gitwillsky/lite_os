# BGP AS 联盟契约

本文件拥有 RFC 5065 联盟的配置身份、可信成员边界、选路及发布语义。
服务寿命、授权来源、配置提交和逐前缀观察沿[BGP 契约](bgp.md)与[配置契约](router-configuration.md#bgp-会话配置)，不另建服务或管理入口。
成员身份、AS 路径和传播边界对 IPv4/IPv6 均生效，路由地址族不改变成员关系。当前联盟专属宿主用例覆盖 IPv4；双栈组合、来宾、FRR/BIRD 及实际流量互通尚待系统验收。

## 配置与身份

唯一配置树的 bgp.local_as 在联盟启用时是本成员 AS，confederation.identifier 是对外公开 AS，confederation.members 是其他成员的 AS 集合。
例如原配置树中的 bgp 对象可为：

```json
{
  "local_as": 65000,
  "identifier": "192.0.2.1",
  "confederation": {"identifier": 64496, "members": [65001]},
  "neighbors": {
    "member": {
      "address": "192.0.2.2", "asn": 65001, "preference": 20,
      "hold_seconds": 90, "retry_seconds": 5, "passive": true,
      "import": {"default": "permit", "preference": 100},
      "export": {"default": "permit"}
    }
  }
}
```

1. confederation 缺省/空值表示普通自治系统；members 缺省为空，允许只有本成员的联盟。
   AS 必须非零；成员解码时排序并拒绝重复，直接构造的配置也必须通过规范集合检查。公开号码与成员号码不要求不同。
2. 同本成员 AS 的邻居为 Internal，集合中其他 AS 为 Confederation，其余为 External。
   router-protocol 拥有唯一 PeerKind；原生会话从配置冻结关系，接收路径、OPEN 数字相等或两字节 AS_TRANS 均不能改变信任边界。
3. 同成员及其他成员连接的 OPEN/AS4 capability 使用成员 AS；对外连接使用公开 AS。
   接收 OPEN 仍按期望实际邻居 AS 验证，不以公开身份覆盖对端身份。对外身份恰等于对端号码时仍保持 External 角色。
4. 反射器客户端只允许同成员 iBGP；跨成员不使用路由反射属性。成员连接属于 eBGP 连接，缺省宣告间隔 30 秒，同成员 iBGP 为 5 秒；显式配置仍可覆盖。
   配置保存、Schema、导入/导出、差异、备份与重建域沿原路径，不增加第二份持久状态。

原生 BGP 工厂及实例版本由 router-protocol::bgp::VERSION 唯一拥有，配置和状态只接收当前布局，具体传输见[BGP 契约](bgp.md#原生服务与授权入口)。
这与磁盘 JSON 版本和网络 BGP 版本无关；旧磁盘配置缺省字段仍表示普通 AS。

## 接收与选路

1. 真正外部邻居或未配置联盟的邻居不得提供联盟段；其他成员提供的路径必须以 AS_CONFED_SEQUENCE 开始。
   违反时按 RFC 7606 TreatAsWithdraw 处理全部可辨认宣告，仍处理显式撤回，既有接收路由正确退休；不把坏路径当空路径接受或杀死整个域。
2. 同成员与其他成员保留 LOCAL_PREF；其他成员未提供时使用显式入口政策缺省值，普通 iBGP 仍要求该属性。
   跨成员接收丢弃 ORIGINATOR_ID/CLUSTER_LIST；MED 与下一跳保留，AS4 重建仍沿唯一 codec。
3. 公开联盟身份出现在任意段构成环路；本成员身份只在联盟序列/集合中构成成员环路。
   原始接收路径与后政策路径都检查，入口排除或替换 AS 不能隐藏真实环路。成员号码仅出现在普通序列/集合时不误判为成员环路。
4. 联盟段不增加选路跳数；MED 分组跳过联盟段，首个普通序列提供相邻 AS，内部空路径/前导集合按本成员 AS 分组。
   真正外部路径优先于联盟成员及 iBGP，后两者在此阶段同级，继续按 IGP 等规则选择，不通过枚举顺序产生额外偏好。

## 发布、拒绝与清理

1. 同成员保持路径；其他成员前置本成员 AS 到首个联盟序列，不足 255 项时合并，否则新开联盟序列。
   对外剥去全部联盟段，再以前置公开 AS 的普通序列发布；同类序列不足上限时合并，达到上限时重新分段。
2. 同成员及其他成员保留逻辑下一跳、MED 与 LOCAL_PREF；真正外部按既有 next-hop-self、MED 与 AS4 规则发布。
   路由反射字段只在同成员内部方向产生；非跨 AS 扩展团体在联盟内保留，对外过滤。
3. NO_ADVERTISE 禁止所有发布；NO_EXPORT 可在联盟内传播，禁止到外部；NO_EXPORT_SUBCONFED 只允许同成员内部。
   对外去环检查目标 AS 的完整路径；发往其他成员只检查目标成员的联盟段，不将普通外部号码重合当作成员环路；原邻居不回送。
   保留团体约束在出口编辑前检查，permit 或删除团体不能绕过原限制；新加团体约束接收者后续传播。
4. RFC 6793 要求不可映射的四字节成员 AS 仅用于成员均已支持 AS4 的联盟；AS4_PATH 不能恢复联盟段。
   OLD 方向如不能表示保留的联盟段或本次前置的成员 AS，按目标拒绝并撤回已宣告路径，不能映射成 AS_TRANS、丢掉成员或重启整个域。
   对外已移除联盟段，仍可沿标准 AS4 辅助属性发布普通四字节路径。
5. AdjRibOut 按冻结连接角色比较真实出口值；只有真正外部可忽略联盟段差异，成员内部的路径变化仍须传播。
   未完整发送不更新发布记录；错误、退出、刷新及配置替换沿原连接/域寿命清理。
   邻居状态的错误字段区分消息容量限制和 AS 不可表示；逐前缀查询仍保留原始路径、已确认选择及完整发送记录，不冒充远端确认。

## 成本与验证边界

成员集合只存于配置，连接保存其冻结角色，选择上下文保存成员/公开 AS；不在每条路由复制联盟配置或增加全局锁、缓存和额外进程。
身份选择为配置时二分查找；接收、去环和发布沿既有路径扫描，前置以一个标量和原切片迭代直接写最终报文，不克隆路径。
出口等价判断使用连接上下文，无逐前缀角色标志；不可表示与容量错误沿同一拒绝清理路径返回。
本功能不改变转发热路径，完整接收/选路/出口规模成本沿既有控制面基准统一评估，不新增微基准或声明规模性能达标。

宿主回归使用生产配置、Session、接收、入口、选路与 AdjRibOut，覆盖公开/成员身份、错误路径撤回、属性边界、保留团体、成员环路、255 项分段和 OLD 逐目标拒绝。
原生服务双架构 Clippy、宿主检查及静态架构检查不能证明来宾管理 RPC、TCP/Port 竞态、协议互通或实际转发；这些仍待统一系统验收。
