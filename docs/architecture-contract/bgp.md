# BGP 契约

本文件拥有 BGP 的格式边界与实现限制；固定来源见[网络规范基线](../standards-baseline/network.md#bgp)。
当前已有原生 IPv4/IPv6 邻居会话、入口配置、反馈选路及受授权来源下发。支持 [MD5 与 TCP-AO 认证](tcp-authentication.md)，尚未完成来宾运行与协议互通验收。
逐邻居入口和出口策略、候选安装检查、双栈发布、路由反射与 AS 联盟已接通。IPv4 单播可使用 IPv6 下一跳，范围见[下一跳契约](bgp-next-hop.md)。

## 原生服务与授权入口

1. `router-config` 的唯一配置树持有可选 bgp 对象，沿同一校验、导入/导出、持久化及备份路径管理；缺省/空值停止整个域。
   `component-manager` 监督 `bin/bgp`，只给配置 owner 路由 `liteos.bgp.Configuration`。BGP 只接管指定域的网络连接和最小偏好受限来源。
   `network-protocol::bgp` 拥有版本 25 的 OPEN 和实例命令。OPEN 传最低偏好、JSON 长度、固定范围标志及索引数。VMO 在 JSON 后按邻居名顺序携带 u32 接口索引，来源与网络 channel 同域。SNAPSHOT 回复长度及状态 VMO。
   未知版本、尾部、句柄数和完整 JSON 先校验；创建后先取得一次真实状态回复，才把初始化视为成功。该握手不代表邻居已 Established。
2. 每域单线程持有全部邻居、RoutingDomain 与一个 Port，属性的 Rc 不跨线程。每邻居至多一个主动与一个入站连接，按实际 Established/OPEN 身份处理碰撞。
   原生 TCP 使用同一双栈 179 监听，仅接受已配置的 IPv4/IPv6 邻居；主动重连、hold/keepalive 全部使用 Session 的单调截止，空闲无限等待。
   邻居 ipv4_unicast（缺省 true）与 ipv6_unicast（缺省 false）独立选择路由族，不随 TCP 地址族推断，至少开启一族；启用四字节 AS 和路由刷新，尚未启用扩展消息。
   address 使用原生 IP 文本；link-local IPv6 须有 interface 名称，其他地址不带 scope；拒绝 mapped 别名。同一链路地址可在不同接口配置，同地址/接口不得重复。
   每次主动连接用实际 TCP 绑定解析接口，入站按真实 peer scope 查询一次接口名再匹配配置；只在当前操作借用事实，不缓存 ifindex 或另建邻居目录。
   实际 link-local TCP 的本机地址及 scope 才授予 SourcePeer 共链路证明，不能从 BGP Identifier 或多跳 TCP 猜测；OPEN 拒绝保护也核对这一范围，不能误保留另一接口上的同地址会话。
3. 每连接持有一个最大 4096-byte 流缓冲、两个发送槽与至多一份 UPDATE；控制消息仍用定长存储；部分发送保留偏移，完整送入 TCP 后才反馈 Sent。
   接收持续推进到 Again 或工作预算耗尽，不把未完整的一次短读当作等待下一边沿的理由。每轮有界推进，预算耗尽合并最多一个 USER 续调度。
   USER 续调度与一次性 socket observer 分开消费；连接 key 单调分配不复用，旧事件不能驱动新 TCP。关闭/重连释放旧流尾部。
   实例能力关闭时沿 Stop 尝试通知全部邻居，通知或某连接清理失败仍释放其余连接和整个域；不在 Drop 中发 RPC。
   单邻居停用沿相同 Stop 发送 Cease / Administrative Shutdown（RFC 4486），只退休该邻居的连接与路由。先登记撤回再提交关闭；失败时保留尚待退休的连接身份，封住该邻居的重连和接纳，等待配置重试。
4. 入口策略可显式配置，未配置的邻居仍保留原始接收但不参与选择；真实 RIB 确认后才提交 Loc-RIB。出口必须独立显式配置；未配置拒绝发布，初始同步完成后仅对已协商的族分别发送 EoR。
   eBGP 缺省拒绝依据 RFC 8212；iBGP 也拒绝是当前本地政策，不将 RFC 8212 的要求扩大到 iBGP。
   状态按邻居报告配置接口、两族协商结果、入口策略及原始接收数，并报告实际待应用工作/已确认协议选择数；后者不是受全局策略影响的最终 FIB 安装计数，不以旧 Forward 或猜测代价冒充准入。
5. Linux 指定系统程序经既有授权设置 fd 查询 BGP_STATUS，普通应用无新 syscall/ioctl/路径；`ipconfig /bgp` 展示实际会话状态、接收数量和当前错误。
   配置变更的失败/重试与观察代际见[配置契约](router-configuration.md#bgp-会话配置)。入口用法见[客户端文档](../../user/libraries/network-config/README.md)。

## 逐前缀路由观察

`ipconfig /bgp IP网段/长度` 通过同一授权设置入口查询 BGP_ROUTES(16)；输入是 tracking::IpPrefix 的规范 network/length，主机位或非法长度拒绝，不隐式执行 LPM。
router-config 在同一配置锁下取得选定域的实例结果与观察代际。原生 ROUTES(2) 走实例协议版本、正文长度及一个查询 VMO，回复一个结果 VMO。
未知字段/版本、尾部与句柄不符在查询前拒绝；Linux 适配仍只搬运 fd/VMO，不解释 BGP 数据或新增 syscall/ioctl。

1. 同一 actor 按当前 TCP 身份查询各邻居对此前缀的全部路径，返回配置名、地址、原始属性与下一跳、判定及已协商的接收路径编号。
   selected 展示普通单路径出口选择，local 标明本地发布候选；originated 区分未配置、暂无依据和已有依据，redistributed 保留其他来源实际元数据。
   本地零下一跳为 next-hop-self 意图。实际出口按会话能力与[下一跳资格](bgp-next-hop.md#发布规则)确定，资格与候选仅表示可参与出口选择。
   exported 按邻居读取当前 TCP 已完整接收的宣告及本端 ADD-PATH 编号。关闭连接即清除，观察结果没有另一份缓存。
2. 判定由 Selector 的同一次候选准入和选择产生，不在查询或另一个比较器中重算：Selected、NotBest、InvalidPeer、ImportPolicy、Unresolved、AsLoop、OriginatorLoop、ClusterLoop。
   NotBest 表示合格候选输给同前缀的协议最佳路由，不虚报某个未记录的比较步骤。Pending 是尚待确认，不能当作已拒绝或已采用。
3. 每条原始接收拥有单字节 RouteDecision（实际结构大小受对齐影响）；Cell 只在同一 actor 的来源确认租约内更新，原始属性不可变，没有第二份诊断树。
   单批准备只积累一个判定字节/候选；提案不积累判定。失败/取消释放临时向量，旧判定不变；确认后沿同一冻结前缀/邻居/路径次序无分配发布并消费待办。
   宣告等价只比较原始属性及下一跳，重复 UPDATE 不因已确认判定而重新进入待办。Cell 不跨线程共享，不新增锁/Atomic 或全局状态。
4. 接收变化或路由图通知仍在等待处理时，回复 pending=true，所有当前接收判定统一为 Pending；selected 明确保留上次确认值。
   初次接收也为 Pending；未配置 BGP 返回真实空结果，配置仍待应用则返回 ShouldWait，不把服务尚未准备当作无路由。

查询成本为每邻居一次精确索引查询，加本前缀实际属性输出；不扫描/复制全表，不执行 RIB 事务或更新选路。
判定捕获复用原选择循环，不重复扫描 AS 去环；确认增加一次相同顺序的候选遍历，临时存储随批次释放。
规模成本沿完整接收/来源确认基准评估，不新增微基准或以小用例宣称规模达标。
既有来源取消/失败、邻居退休/主备、重复 UPDATE、双族与政策用例覆盖判定寿命和原值保留；授权 RPC、来宾命令及互通仍待系统验收。

## 入口政策、反馈选路与发表

邻居的可选 import 属于唯一持久配置树，缺省拒绝，不以会话 Established 代表允许采用路由。
规则按首个匹配终结；前缀/长度范围、有效四字节 AS 包含/路径正则及三类团体条件取 AND，每个集合条件要求包含全部指定值。
无规则命中使用显式 default。外部邻居用政策的 degree，同成员与其他联盟成员优先保留收到的 LOCAL_PREF。允许动作可覆盖 degree、全局下一跳及 ORIGIN/MED，IPv4 也可改用 IPv6 下一跳。
degree 为零仍合法，与来源管理距离无关；这些是后政策值，原始接收属性保持不变。ORIGIN 与 MED 支持设置，MED 还可显式删除；三类团体可替换、删除及添加；支持有序 AS 路径前置及指定 AS 排除；
指定/全部 AS 替换及路径正则匹配已接入；语法与编译预算见[路径筛选契约](router-configuration.md#bgp-as-路径筛选)，联盟身份与传播边界见[联盟契约](bgp-confederation.md)。
resolve_via_default 缺省为 false，逐邻居明确允许默认路由证明下一跳；策略允许不等于安装后可达。

1. 配置 owner 从实际 RIB 工厂取得 BGP 来源能力，最低管理距离为本域各邻居距离的最小值；域创建只移交该能力与其授权元数据。
   协议 actor 没有工厂权限，不能靠修改元数据扩大授权。每条 TCP 用单调不复用的连接身份登记，重连不与旧选择混淆。
   RoutingDomain 的 retired 集合只保留尚待撤回确认的身份；最后一族工作确认后清除，其他新身份可同时登记，不阻塞所有邻居。
2. UPDATE 与退出变化先进入域的 pending，原生 actor 按首次工作起 50 ms 合并；没有工作不设轮询截止。
   来源是完整替换，因此本轮重新考虑全部接收及已选前缀。入口允许的候选先形成未验证提案，仍保留 Unresolved。
   RoutingProposal 只提供来源编码，没有 commit；不能将提案冒充 Loc-RIB 或伪造零代价/当前可达。
3. 来源 PREPARE 冻结全来源候选图，同时检查允许候选安装后的可达性，协议只用返回的证明重选。
   编码一致且选中路径或复探义务变化时确认，随后提交本地 Loc-RIB。两者均无变化时撤销候选。
   不一致则撤销该试算，用新提案重新准备；不复用旧图证明，也不把一次反事实检查当作整批确认。
4. 同一可见代际的重复提案用 Brent 环检测拒绝，临时只保留一份来源检查点；代际改变重置检查，不保存全表历史或设随意迭代上限。
   分配/编码失败不提前提交本地表；租约竞争保留 pending 按原合批截止重试。未收敛、其他致命错误或确认未知结束域，关闭来源走正常撤回。
   不把丢弃本地 guard 当作外部必已回滚；RIB 退出同样结束域，持久配置由配置 owner 重放，不恢复旧动态状态。
5. 原生 actor 订阅已确认解析图变化。失效路由撤下后，仍被检查引用的失败网关继续由 NET 复探，收到有效回复触发重新选路。
   watcher 与 source 关闭均经原 Port 处理。无变化的复核不确认，空闲时没有周期重算。

当前入口逐条首匹配，完整重算会扫描原始路由并临时排序允许候选，持有 O(允许候选数) 分类/检查与来源正文。
每轮还会编码完整来源并进行原生 RPC；同步重算对会话截止的影响、规则规模、全表峰值内存及收敛延迟仍须沿完整服务基准评估。
不增加报文转发热路径、跨轮政策缓存或逐路由常驻证明；没有实测依据时不声明全表性能达标或最优。
既有接收/选择/来源用例覆盖规则、原始属性不变、未验证提案不可提交、退休身份及候选图到 NET 的确认次序。
这些 host 用例不直接执行原生反馈 RPC 循环，不替代来宾异常竞态、FRR/BIRD 互通或跨网卡转发验收。

## 出口策略与实际发送

邻居 export 独立于 import，缺省拒绝；显式 default 和有序规则共用 RouteRule/RouteAction 的全部条件，不复制第二套匹配解释。
允许动作可覆盖可用地址族的全局下一跳、ORIGIN/MED 和发往 iBGP/其他联盟成员的 LOCAL_PREF。联盟外部不携 LOCAL_PREF，普通 iBGP 保持分割水平。
IPv6 共链路证明、辅助地址及资格变化由[下一跳发布契约](bgp-next-hop.md)拥有；同批发送投影共享，容量及等价比较包含辅助地址。
NO_ADVERTISE 禁止全部发布，NO_EXPORT 限于本联盟，NO_EXPORT_SUBCONFED 限于同成员；目标去环按可信成员边界检查，原始邻居不回送；permit 不能绕过限制。

1. AdjRibOut 归实际 TCP，按前缀和路径身份记录完整送入 TCP 的后政策值。单路径和 ADD-PATH 共用同一索引、策略与发送完成逻辑。
   ADD-PATH 按来源连接及其接收编号识别学习路径，本端另行分配发送编号。替换、撤回和重发保留编号。超过递增范围时只复用同前缀已退休的编号。
   新连接以有界游标扫描当前目标。来源确认后分发变化前缀，待发索引每条路径只保存一个截止，编码时读取最新值。
2. 每连接至多一个在途 UPDATE；按实际出口属性等价合并多个目标，撤回也可合批，不混合不同属性或宣告/撤回方向，不等待凑批。
   同一批只持一份冻结属性及各目标身份/预留清理节点；完整编码成功后才消费本批待办，发送期间的新变化保留，不能丢弃部分帧。
   只有整帧送入 TCP 后才无分配更新实际宣告数、发送时间与清理截止。ADD-PATH 发送数按实际路径统计。
   两个 FIFO 发送槽保留控制消息空间，部分偏移由 Transport 独占。关闭 TCP 同时退休整批、发送记录、截止索引与流尾部，新 TCP 不沿用旧记录。
3. 每前缀宣告与撤回均遵循 RFC 4271 §9.2.1.1；advertisement_seconds 缺省 eBGP 30/iBGP 5 秒，显式零关闭限速。
   同前缀共享发送间隔，属性相同的路径可在同帧合并。撤回后的记录保留一个间隔，清理节点在发送前预留，到期释放。
   Port 等待最早截止，帧背压期间只等 socket 就绪；按轮预算推进收发，来源提交后主动唤醒出口工作，不依赖其他网络事件。
4. 外部方向以实际 TCP 本地地址作 NEXT_HOP、prepend 本连接真实 AS（联盟下为公开身份），按协商宽度生成 AS4 辅助属性，去掉联盟内部段。
   同成员与其他联盟成员方向保留逻辑下一跳及已计算 degree；学习的上游 MED、LOCAL_PREF 和反射字段不泄漏到联盟外部 AS；本地发布的 MED 保留，显式出口 MED Set 为本地重新声明，非跨 AS 扩展团体同样过滤。
   普通/大团体、聚合器、ATOMIC_AGGREGATE 与未知可传递属性沿标准传播，Partial 不丢失；比较后政策出口值，忽略未传播的 MED/LOCAL_PREF 等变化。
5. 每次准备最多检查 128 个待办，在标准消息字节上限前结束合批；异组目标保留原截止，有界向前合并同组，不要求网段连续，不排序全表或增加常驻分组索引。
   同一帧只合并同族同编码目标，MP 属性跨 255 字节时精确增算头长。共享属性先比较身份，再按实际可编码字段比较。撤回沿用已发送宣告的编码。
   Update::emit_with 在最终属性区调用生成器，packet-wire 拥有 UPDATE、NLRI 和属性布局。最多使用 2688-byte 临时 NLRI 窗口，含每条路径的四字节编号。
   单个目标能放下而整批超限时拆批，不能误判为目标不可发布；单目标追加 AS/AS4 后超长才按 RFC 8654 §4 撤回旧宣告，保留最近被拒绝目标供查询，不重启整个域。
   分配或其他编码失败结束域，不能静默跳过更新后继续报告准确状态；超长属于逐目标拒绝，不与资源失败混同。

现有 Session 夹具检查实际对端解码、OLD/NEW AS4、属性边界、缺省拒绝、保留团体、分割水平、部分帧后的变化、宣告/撤回间隔及超长撤回。
多目标用例沿同一入口验证交错属性分组、完整遍历、消息容量拆批、发送前不记账、批内目标发送期间撤回和刷新跟进；不另建出口模拟器。
宿主 ADD-PATH 用例覆盖双栈实际解码、备选变更、逐路径撤回、重发编号和共同发送间隔。原生 TCP 部分写、FRR/BIRD 与跨网卡转发仍待系统验收。
每邻居保留 O(R) 路径记录和 O(P) 截止索引。多路径间隔查询为该前缀的 O(K)，队列扫描仍受 128 条预算。编号回收只在递增区间耗尽后搜索同前缀记录。
属性和报文按批分配。初始同步和刷新按 32 条预算展开，来源重算及 RPC 仍是完整替换。
本轮以既有真实报文用例验证合批与容量，不新增微基准；完整全表峰值内存、传播吞吐和会话延迟沿原控制面规模基准统一评估，不声明规模性能达标。

## 本机网段宣告

原生 Connection/借用 Io 只向同 crate 的 Sessions actor 开放：父负责监听、碰撞、控制与编排，Connection 统一拥有单 TCP 的协议事件、收发、出口与清理，不复制 Session 或增加线程。
原生配置与观察定义见 [配置契约](router-configuration.md#bgp-本机网段意图)。RoutingDomain 只持配置网段及最近确认的分发资格，所有本机网段共享一份 IGP ORIGIN/空 AS_PATH 基础属性。
Local、Forward 或明确的 Discard 汇总路由允许本机宣告，NoRoute/Unresolved/Unreachable/Prohibit 不允许；默认网段也必须精确存在。
这项分发意图不反向安装为 RIB 路由，不伪造邻居 UPDATE/身份；真实学习路径仍按原反馈选路和来源确认保持，故宣告不能证明自己可达。
单路径出口依次取有效显式网络、重分发与最佳学习路径。启用 ADD-PATH 时，当前本机发布候选与所有已确认合格的学习路径均进入同一出口策略和发送队列。
本机路径发往 eBGP 时前置真实本地 AS，发往 iBGP 携标准缺省 LOCAL_PREF。两方向均按[下一跳发布规则](bgp-next-hop.md#发布规则)选择本机地址，出口政策可拒绝或编辑。
资格批次先完整验证定义，再按真实变化预留返回空间，最后无失败接管；失败保持旧资格。证明未就绪初始不活跃，来源或观察能力退出沿域清理撤销，不缓存另一份转发表。
观察的 selected.local、originated、域 originated_routes 及逐邻居 exported 区分本机意图、已学选择与实际发送；pending 保留最近完成值，不把等待当作成功。
成本为 O(K) 资格/观察定义、单份共享基础属性、O(K log F + 结果成员) 冷查询；资格不变不分配返回数组，只有变化进入原出口索引。
初始同步合并三个有序来源并限制每轮展开。其他来源筛选、增量确认、属性与成本见[重分发契约](router-configuration.md#bgp-其他来源路由发布)。
现有 Session/RIB 用例串联规范配置、默认/父/子网段、Discard、错误批次不变、双方向真实报文、完整发送前后观测、资格丢失撤回及恢复学习出口；原生 RPC、热配置与互通验收仍待完成。

## 邻居请求路由重发

会话宣告 RFC 2918（能力 2）和 RFC 7313（能力 70），按已协商的 IPv4/IPv6 单播族处理邻居请求。双方宣告能力 70 时启用增强标记，否则按 RFC 2918 忽略保留字节。
未匹配到开始标记的结束标记忽略。增强模式未知 subtype 忽略，起止标记长度错误发 7/1，附完整帧并沿同一会话退出流程处理。
管理端按配置名和已协商的单播族请求刷新。只在当前已建立连接且对端宣告接收刷新能力时排队。同一族的待发请求合并，随当前 TCP 退休。[授权命令](router-configuration.md#bgp-会话配置)

1. AdjRibOut::refresh 只登记一个索引游标；新请求合并为一次跟进，不反复倒退当前游标，不按请求积累全表副本。
   每次准备最多推进 32 个记录；重发待办达此额度后停止展开；普通队列繁忙不阻止刷新，背压/MRAI 有未来截止时不因尚有游标而零截止忙转。
2. 记录用 refresh_pending 区分实际重发与网络重算义务，同 owner 的聚合限制积压，远端重发不能被普通去重吞掉；每次发送仍读取当前已确认选择并执行完整出口政策。
   未宣告/已撤回目标不从旧值复活；新的正常变化仍进入唯一 changed 工作。队列与记录分配失败沿原域错误清理，不默默跳过目标。
3. 完整帧编码消费此前重发义务，后来的请求保留；部分 TCP 帧不取消或交错，只有实际送完才更新 sent_at 与宣告计数。
   增强开始标记完整送入 TCP 后才扫描该族。游标结束且该族重发全部送出才发送结束标记；新请求在当前结束后启动下一轮。与初始同步 EoR 独立。

接收起始标记按邻居和族推进代际，保持旧路径可用。重复 UPDATE 更新收到的路径代际并保留选路判定。结束时预留撤回队列，只移除遗漏的路径并触发合并选路。
常规开始为 O(1)，每条候选持一个 u32 代际。结束线性遍历该族，仅为实际撤回预留空间。主动请求每连接两族各一个待发位，复用现有发送队列。全表规模沿既有传播基准验收。
宿主用例覆盖主动发帧、增强边界、发送间隔、遗漏撤回及畸形标记。ORF、Graceful Restart、配置替换时保留会话和来宾互通仍待完成。

## 标量属性政策

RouteRule 的 origin 匹配改写前的 igp/egp/incomplete；med、local_preference、as_path_length 使用含两端的 {start,end} 范围，倒置范围在配置校验阶段按具体字段拒绝。
入口匹配原始属性，local_preference 使用外部策略缺省或内部收到值形成的初始 degree；出口匹配已确认属性及 degree，不用原始可选 LOCAL_PREF 冒充选路值。
缺失 MED 不匹配任何 MED 范围（包括零）；这与最佳路径比较的缺省零分属不同契约。AS 跳数复用 RFC 4271/5065 选择语义：序列按成员、集合一跳、联盟零跳。
所有条件取 AND，首条命中终结；先分类再改写，不以本条动作后的新值反过来满足本条条件。RouteAction::Permit 的 origin 改写类型同上；med 缺省保持，Set 携 u32，Remove 删除。
范围复用固定 Serde/Schemars 的 RangeInclusive 模型与 Schema；分类不分配、加锁或保留逐前缀缓存，仅在需要时计算一次 AS 跳数。规模成本沿既有控制面基准评估，不另建微基准。
入口 ImportDecision 只给出逻辑编辑；原生 actor 先从原始接收捕获允许候选，再经 RoutingDomain::project_attributes 取得同一池中的实际后政策属性。
propose/prepare 分类回调明确借用这份冻结属性，Selector 的 ORIGIN/MED 比较及最终 SelectedRoute 均使用它，不在编码末尾才改字节。

1. Contents 的唯一 key 同时用于规范排序与借用投影比较；Pool::find_by 复用 AVL get_by，先查询已有内容，命中不分配。
   新的不同值只克隆共享子组件句柄并分配控制块/节点；标量未变直接复用原属性，不创建长期政策缓存或变更历史。
2. 反射列表与未知可传递正文也通过同一 residency 实现共享，Clone 不复制列表/字节；空组件无对象。
   查询比较器只读规范 key，不分配、不回入池或析构 Shared；RefCell 借用结束后才返回句柄，确认/退休时没有在途池借用。
3. 原生分类工作区临时持每个允许候选的属性引用，支持多次候选图反馈而不重新捕获字节；资源失败释放临时引用，保留原始接收与旧 Loc-RIB。
   只有实际来源确认后才提交包含新属性的协议选择，清除政策后能从原始候选重选，不把投影写回 Adj-RIB-In。
4. 出口在同一池中独立投影，不改变 Loc-RIB。外部方向缺省删除普通上游 MED；显式 Set 作为本地声明传播，Remove 不编码 MED。
   相同实际出口属性不重新宣告，标量改变可产生标准 UPDATE；反射域 iBGP 可筛选及编辑团体，仍校验拒绝 ORIGIN/MED 与关键属性覆盖。

既有属性用例检查重复投影复用、共享引用归还；政策用例串联配置往返、范围拒绝、标量筛选、ORIGIN/MED 选路及实际出口撤回，确保缺失 MED 与已确认 degree 不被默认值替换。
原 NET 事务用例同时保护投影到真实候选检查/确认的次序。它们不覆盖原生 RPC 故障竞态、协议互通或全表性能。
成本决策：命中查询为 O(log U) 次规范比较，不增加逐包工作；只有不同结果增加属性节点，原生候选工作区增加一个共享引用。
原始捕获新增子组件索引的比较/控制块成本，规模收益取决于共享度；全表加载、峰值内存与传播仍沿既有控制面基准评估，不宣称已最优。

## 团体集合编辑

RouteAction::Permit 的 communities/extended_communities/large_communities 直接拥有三类 CommunityEdit，未配置保持原值。
每个编辑按 replace（缺省用原集合）→ remove → add 执行；replace=[] 清空，删除后同值再添加则保留。规则仍首个匹配终结。
各列表是集合，JSON 解码时一次排序去重；手工构造模型须通过同一配置校验。规范化不改变规则、DNS 或其他有序数组。

1. 已配置编辑才拥有独立 Box，普通/拒绝规则只持可空指针，不为全部规则内嵌九个向量头；JSON/Schema 不因该存储方式产生另一种格式。
   ImportDecision 只借用唯一动作，候选工作区不逐前缀复制集合或多个集合描述符；AttributeChanges 仅在投影时生成借用视图。
2. 两路有序合并加单调删除 cursor 惰性产生规范结果；没有变化复用原句柄，空结果删除属性，命中分组件池也不分配。
   只有新的不同集合才按实际项数预留并捕获，再驻留完整属性；未受影响的路径、反射列表、未知 payload 仍共享。
   保留属性的 Partial 不清零；删除整个属性时清除相应 Partial 位，避免缺席值仍携带无意义身份。失败释放本轮组件，不修改旧属性。
3. 入口规则先匹配原始接收，编辑后的值用于本次协议选择及后续出口条件；清除政策仍能从 Adj-RIB-In 重算。
   出口先按 Loc-RIB 检查已有 NO_ADVERTISE/NO_EXPORT/NO_EXPORT_SUBCONFED，再执行出口编辑；出口清除不能绕过先前的准入限制。
   新增的保留团体是给接收邻居的后续传播约束，必须随本次公告发送，不能把它误作本次本地拒绝。该顺序对照固定 FRR 10.0 bgp_announce_check。
4. 扩展团体仍按实际 AS 边界过滤非传递项；空集合不编码为空属性。编辑集合超过本方向消息上限时沿逐目标拒绝/旧宣告撤回，不重启整域。
   三类编辑均复用现有唯一属性编码，不复制另一份 wire 模型或绕过来源确认与发送背压。

集合用例对照独立集合代数覆盖替换/删除/添加组合及引用退休；政策用例复用原会话夹具串联配置规范化、入口新标签匹配、实际对端解码、接收方传播限制、清空和超长撤回。
传输与属性政策用例按领域分开，只提取共用装配，未新增生产诊断入口或独立运行环境；原生 RPC/故障竞态、完整互通仍待系统验收。
成本决策：有序合并 O(B+D+A)，驻留查找至多 O(log U) 次规范比较，只有新集合/完整属性捕获存储；不排序逐前缀集合、不保留政策缓存。
配置解码增加一次排序/去重，全部函数只在控制面；沿完整全表/规则规模基准评估比较开销、峰值内存与传播，不以小用例声称性能达标。

## AS 路径编辑策略

Permit 的 as_path_prepend 是非零 ASN 的有序列表；省略或空列表保持路径，保留重复次数，配置不排序/去重。
as_path_exclude 为非零 ASN 集合，解码时排序去重；从所有段删除全部命中值。省略/空集合保持原值，允许结果为空路径。
as_path_replace 为可选 {from,to}：from 缺省替换全部幸存 AS，否则替换全部匹配出现；to 为显式非零 AS，不隐式使用本地 AS。未知字段/零值拒绝。
顺序为删除 → 替换 → 前置；后来的前置值不被本条规则的删除/替换处理，原始 Adj-RIB-In 不改变。
入口先匹配原始路径，再投影供选路及后续出口匹配；编辑后的路径长度参与选择。去环同时检查原始和修改后的路径，不能靠删除本地 AS 绕过；清除策略重新使用原始接收值。
出口独立投影；外部发布时由唯一 codec 再前置实际本地 AS，顺序为本地 AS、策略列表、原普通路径，不改变 Loc-RIB。
出口替换或前置 AS 后，按接收邻居所属 AS 及联盟身份再次检查去环。结果包含会让该邻居判环的身份时，停止发布该网段并撤回此前的宣告。
没有增加 ASN 的动作沿原去环结果，无额外路径扫描。接收方去环语义见 [RFC 4271 §9.1.2](https://www.rfc-editor.org/rfc/rfc4271.html#section-9.1.2) 和 [RFC 5065](https://www.rfc-editor.org/rfc/rfc5065.html)。

1. PathPool::project 用唯一借用视图查询最终规范身份，不驻留删除/替换后的中间路径；删除后空段消失，保留幸存联盟前缀，再插入普通序列。
   同类相邻序列包含删除后新相邻的段一起合并；序列替换保留顺序/次数，集合替换用有序删除/插入去重，不排序或分配每段的工作数组。
   集合缺少待替换 AS 时不凭空插入目标；全部替换使每个非空集合成为单成员，独立集合边界保留。
   此操作保持已有联盟信息；成员关系来自唯一配置，向外部发布时仍由原 codec 移除联盟段。
2. 比较次序与捕获路径一致；命中只克隆共享句柄，只有新结果才按实际容量分配。最后引用释放时退休，不增加政策缓存或逐前缀路径副本。
   内部长度越界或分配失败返回资源错误；临时结果释放，原始接收与旧选择仍有效。
3. 发送沿现有 255 项重分段及 AS4_PATH 投影；本地编辑超过标准消息容量时只拒绝该目标并撤回旧宣告，不能升级为整域格式失败。
   反射域 iBGP 的非空前置/排除及任何替换在配置校验时拒绝，保持反射的 AS_PATH；普通域及外部规则使用同一投影。

Candidate::received_path 只借用实际 Adj-RIB-In，post-policy attributes 参与比较；提案和确认共用原始/编辑后 AS 去环，不新增持久副本。
既有路径用例覆盖空路径、联盟前缀、空段删除/序列合并、集合替换去重/顺序、驻留复用/退休及 255 项分段。
政策用例串联配置、选路、原始/编辑后去环、OLD/NEW 对端解码、动作清除/等价去重与超长撤回；schema 与反射限制沿同一持久模型检查。
这些宿主结果不能替代原生 RPC、互通及全表验收。排除集合只在配置解码时排序，视图成员查询为 O(log E)，至多 O(log U) 次规范路径比较。
新结果只分配实际剩余/前置项数，不为原路径上界保留容量；全部位于控制面，沿完整加载/传播基准评估，不新增微基准或宣称规模达标。

## 路由反射

唯一配置树在邻居上保存 route_reflector_client，缺省为 false；只允许同一本地 AS 的 iBGP 邻居拥有该角色。
显式 cluster_id 启用反射域；未指定但配置了客户端时，簇身份采用本地 Identifier。没有簇与客户端时保留普通 iBGP 分割水平。
簇身份是四字节不透明值，与邻居及路由的地址族无关；双栈共用角色、去环和反射属性，IPv6 沿 MP_REACH/MP_UNREACH 发布与撤回。修改角色或簇仍按既有配置寿命重建域。

1. 有效簇只由持久配置投影至 SelectionContext，RoutingDomain 只读转交它；同一已连接 ExportContext 冻结该值。
   Peer 保存配置 owner 提供的客户端角色，不从 OPEN、地址或路径猜测。状态按域报告实际簇身份，按邻居报告配置角色，普通应用没有新授权入口。
2. 非客户端学入的 iBGP 最佳路由只向客户端反射；客户端学入的路由可向客户端及非客户端反射，不回送原始连接或起源标识对应的邻居。
   反射不替代入口/出口显式准入、AS 去环或下一跳证明，也不选择另一条非最佳路由来绕过出口拒绝。
3. 已有 ORIGINATOR_ID 原值保留，否则使用实际来源邻居的 BGP Identifier；CLUSTER_LIST 必须前置本地簇，并保留原列表顺序。
   出口仅额外保存一个可选起源标量；簇随连接冻结，原列表仍借用共享 RouteAttributes，尺寸预检与写入均沿相同迭代器，不按前缀复制列表。
   返到本簇或本机起源的路由由现有选择器拒绝，并沿正常来源确认/出口撤回；重复客户端角色不构成绕过去环的理由。
4. 反射保留 NEXT_HOP、AS_PATH、LOCAL_PREF 与 MED；反射模式下 iBGP 的入口/出口规则可筛选及编辑团体，配置校验拒绝 degree/下一跳、ORIGIN/MED 覆盖与 AS 路径编辑。
   该边界遵循 RFC 4456 §10，不默默忽略用户要求的动作；eBGP 规则及普通非反射域的原有覆盖能力保持适用。
   原始反射属性不能经政策修改；向 eBGP 发布时仍去除反射字段，不将簇信息泄漏到外部 AS。

既有出口夹具用 IPv4 检查配置到真实 Session 报文的角色组合、起源保留/生成、列表前置、关键属性不变、返回簇拒绝及旧宣告撤回；IPv6 组合仍待系统验收。
配置原用例检查非法外部客户端、默认/显式簇与不可允许的内部改写；没有新增独立运行环境或诊断入口。
额外常驻量为每邻居角色、每连接簇及每已发送/在途反射路由的起源标量，不创建另一份路径/列表 owner。
这些检查不替代原生 TCP/Port、冗余 RR 拓扑、实际收敛与 FRR/BIRD 互通验收，目标规模仍沿完整控制面基准评估。

## 格式所有权

`libraries/packet-wire::bgp` 唯一拥有消息头、OPEN/UPDATE 与双栈普通 NLRI 的字节布局。
只依赖 core，无堆分配、锁、全局状态、计时器、设备/RIB 权限或 Linux ABI；协议进程不能再复制字段 codec。

1. Header 检查十九字节共同头的 marker、类型及长度，完整正文缓冲分配前即可校验上限。
   HeaderError 区分截断、Marker、Length、Type，供会话 owner 选择对应 NOTIFICATION，不要求它重新实现头解析。
   Frame::read 借用流缓冲的首个完整帧及未消费后缀，不完整返回 None；非法完整头立即失败，不扫描 marker 猜测重新同步。
   Frame::parse 面向独立帧，额外尾部拒绝。两者共用同一 Header，不另建串流解析状态或复制完整消息。
   extended 是调用方向已授权的接收/发送能力，不能因本地实现支持便设为 true；普通上限 4,096，扩展上限 65,535。
   OPEN 始终受 4,096 限制，KEEPALIVE 必须为十九字节；UPDATE/NOTIFICATION 保留各自最低长度。
   当前 ROUTE-REFRESH 仅固定四字节正文，保留 AFI/SAFI/subtype；不支持 ORF 的可变长消息，不据 subtype 宣称已协商增强刷新。
2. OPEN 的版本、两字节 My AS、hold time 与 Identifier 保留原值；格式捕获不替代版本、AS_TRANS、对端身份和计时协商。
   RFC 9072 由非零 Non-Ext OP Len 后的类型 255 识别扩展；识别后忽略前者数值，参数总长和每参数长度改用 u16。
   普通总长度恰为 255 不等于使用扩展；普通/扩展参数沿同一 owner 解码，保留未知/重复参数。
   参数类型 2 才可解释 capability TLV；参数 framing、capability framing 和已知 capability 值宽度分别检查。
   当前类型化 MP、Extended Next Hop、Route Refresh、Extended Message、四字节 AS 与 ADD-PATH；未知 capability 保留原值。
   Capabilities::emit 清 MP 保留字节，Open::emit 写版本 4、拒绝 1/2 秒 hold time、必要时选扩展参数布局，均先检查全部范围再写输出。
3. UPDATE 先捕获撤回、属性和基础 IPv4 NLRI 的独立区间；一个属性的内容错误不影响其他区间读取。
   Attributes::parse 提供完整验证视图；scan/Update::scan_attributes 顺序交出有效前缀，首次结构错误报告一次并停止。
   后者供 RFC 7606 保留先到的 MP NLRI，不能跳过错误裁决或按猜测的下一属性位置继续扫描。
   属性短/扩展长度均检查；未知/重复项、原 flags 保留，必需属性、重复/flags 处置仍归协议 owner。
   发送按值长度选择长度字段，清 flags 低四位；接收不把这些应忽略位误判为错误。
   ORIGIN/AS_PATH/NEXT_HOP/MED/LOCAL_PREF/ATOMIC_AGGREGATE/AGGREGATOR、三类 community、反射字段与 MP 属性可独立检查内容。
   列表宽度和非空要求、固定值宽度/枚举检查不等于属性传播策略、团体匹配或最佳路径已实现。
4. AS_PATH 的两/四字节宽度由所属方向协商给定，不按长度猜测；AS4_PATH/AS4_AGGREGATOR 固定四字节宽度。
   空路径合法，零项/未知类型/截断段非法；set、sequence、联盟段类型保留，不在格式层改写路径含义。
   AS_PATH 生成检查每段 1..255 项与两字节数值上限，直接写最终属性值；不会截断四字节 AS 号。
   AS4 重建、发送投影、选路跳数及纯选择核心归 system/bgp；基本出口及按成员关系的 AS prepend 已接入，联盟成员准入见[联盟契约](bgp-confederation.md)。
5. NLRI 按协商检查双栈前缀及可选四字节路径标识。读取时规范化无关尾位，发送不泄漏主机位。
   MP_REACH 保留族/SAFI、原始下一跳与 NLRI，接收忽略 reserved；MP_UNREACH 保留空列表供 End-of-RIB。
   未知 AFI/SAFI 仍保留属性原值，前缀解码拒绝 VPN 与带标签布局。基础和 MP 单播共用同一前缀解析。
   下一跳的长度组合、链路范围与跨族下一跳须按会话协商接纳；格式捕获不建立可达性证明。
   MP 生成从所属 Nlri 取得 AFI，清 reserved，直接写最终属性值；最终可达证明仍应从授权 RIB 跟踪能力取得。

## 会话状态与 OPEN 接纳

system/bgp 的 Session 独占 Config 投影、本 TCP 的实际 OPEN 方式、六状态、协商结果与 retry/hold/keepalive 的绝对单调截止；会话/接收核心不分配，路径驻留使用 alloc 与 fallible-tree，不依赖内核或 Linux UAPI。
Config 是从唯一配置树投影的不可变连接参数，不是另一份持久配置文件/Schema；参数改变关闭旧域并重新创建，不能人工同步两份政策。

1. Config 检查非零 AS/Identifier、合法 hold time 和非零 retry；Identifier 按 RFC 6286 的非零整数检查，不要求它是本机或单播地址。
   emit_open 复用唯一 codec，在栈上构造能力并携真实四字节 AS。My AS 不可表示时使用 AS_TRANS，基础 IPv4 重试不含可选参数。
   接纳检查版本、AS、Identifier/同 AS 重复 ID、hold time、可选参数/capability，未知 capability 忽略，未知参数的错误通知保留完整原参数头/值。
   两个 NEW speaker 使用 capability 中的真实 AS 取代 My AS；重复相同 AS4 接纳、冲突拒绝，不从 My AS 截断值恢复身份。
   hold time 取双方最小值，任一为零则关闭周期 hold/keepalive；MP 按交集，未见 MP 时允许配置中的基础 IPv4；没有可用共同地址族则以 2/7 拒绝，不把空协商报告为成功。
   扩展消息、刷新与跨族下一跳分别保存方向授权。跨族还须协商 IPv4 MP。ADD-PATH 只在共同单播族按双方实际宣告的互补方向启用，布局冻结至连接退出。
2. Start 主动进入 Connect 并请求连接，被动进入 Active 且无主动重试；重试/失败按唯一 retry 截止推进，没有定时轮询。
   Input::Connected 冻结实际 OpenOffer，进入 OpenSent、请求发送 OPEN 并启动 240 秒初始 HoldTimer；尚未收到 OPEN 时不能使用未协商的 hold time。
   有效 OPEN 进入 OpenConfirm，请求初始 KEEPALIVE；对端 KEEPALIVE 才进入 Established。
   KEEPALIVE 完整送入 TCP 后才设置下个发送期限，已发送 UPDATE 同样刷新发送计时；收到 KEEPALIVE/UPDATE 刷新 HoldTimer。
   保活到期只交出一次发送工作，等待 Sent 再重武装；发送背压不能形成到期忙循环，HoldTimer 仍能结束卡住的连接。
   旧 timer 唤醒按当前截止复核；重复当前连接确认不关闭活跃连接。传输 owner 必须先过滤已退休连接/尝试的旧事件，不能把它们交给新会话。
3. 每次终止只有一个 Close 清理义务：本地通知为 best-effort，失败也必须关闭 TCP；已建立连接还必须完成来源撤回。
   withdraw_routes 保存退出前的路由清理义务，send_extended 保存通知发送权限；协商随状态立即退休，执行器不能再查询它来猜测清理或发包规则。
   received 借用对端 NOTIFICATION，执行器仅记录错误码，不能回发；同帧执行完成后才退休输入。本地主动关闭/碰撞清理不覆盖真正错误。
   通知发送失败不得短路 Close/撤回；撤回未完成不得继续新连接，actor 必须保留实际未完成工作并重试，不能假装转换到 Idle 就已完成外部清理。
   普通失败在 Idle 持 retry 截止；Stop 关闭全部期限、不重连。收到 NOTIFICATION 不回复另一个错误通知，异常状态消息带 RFC 6608 子码和原消息类型。
   碰撞 loser 停止且不重连；prefer_outgoing 按较大 Identifier 发起者裁决，ID 相等的 eBGP 按较大实际 AS，已有 Established 由 peer owner 优先保留。
   Input::CollisionLost 来自原生 peer owner 对两条实际连接的裁决，纯比较函数本身不拥有连接。
4. Established 的 UPDATE 先经下节接收裁决及 AS4 接收重建，才移交增量决定；严重错误沿同一关闭命令处理，不在解析途中发布路由。入口、选择/Loc-RIB 与来源沿下节唯一反馈链路推进。
   Route Refresh 必须已在本地宣告，未宣告的族/SAFI 忽略；原 reserved/subtype 按基础刷新语义处理，不宣称增强刷新已接入。
5. OPEN 阶段收到 2/4 后，若允许 IPv4，则同批 Close/OpenRejected 请求无参数重试；仅允许 IPv6 时不能降级。2/7、再次拒绝或没有共同地址族暂停该邻居，配置重建后再协商。
   NeighborState::open_offer 唯一持有下一次主动/被动尝试方式；None 同时阻止启动循环、入站接纳及其他半开连接。并发输家不能停用已建立连接，成功连接按自己的真实 offer 更新下次方式。
   本次 offer 不随邻居重试决定改变；基础模式不授权 AS4 路径、IPv6、扩展消息或刷新。地址族 TLV 由 packet-wire 的 Capabilities::{unicast,bytes} 同时供 OPEN 与拒绝通知使用，不在协议 actor 重建布局。
   新增状态仅为每邻居/连接标量，仍用两槽无分配 Effects，无额外锁或轮询；仅握手拒绝检查同邻居的已建立身份，成本 O(邻居数)。不新增微基准，沿完整会话/收敛基准评估。
   Effects 只有固定两槽，最坏为“取消旧尝试、发起新尝试”；不新增锁、缓存、堆消息或协议状态副本。

## UPDATE 接收裁决

received module 只由 Session 为同一 Frame 的 UPDATE 视图/原包调用；ReceivedUpdate 的私有字段保证原包、属性区与结果属于同一次输入。
整个消息检查完成才返回增量决定；不在逐属性/前缀解析期间修改来源或下一跳状态。

1. 先检查基础撤回和宣告 NLRI，再顺序捕获属性与完整原 wire；唯一 codec 拥有长度布局，错误通知不在会话层重建头字段。
   普通重复属性只处理首项，后续副本不能修复先到的坏值；MP_REACH/MP_UNREACH 重复则重置会话，即使该族未启用也不例外。
   未知 well-known 属性产生标准 3/2 通知并附原属性；未知 optional non-transitive 忽略，optional transitive 保留给后续传播 owner。
   已知属性检查 Optional/Transitive 期望值，well-known/optional non-transitive 的 Partial 置位也按错误处理；低保留位不误作错误，原属性不是可直接发送的最终属性。
2. ORIGIN/AS_PATH/NEXT_HOP/MED、内部邻居的 LOCAL_PREF/ORIGINATOR_ID/CLUSTER_LIST，以及三类 community 的内容错误按 TreatAsWithdraw。
   路径中的 AS 0 按 RFC 7607 分类；坏 ATOMIC_AGGREGATE/AGGREGATOR 与 OLD peer 的坏 AS4 辅助属性只丢弃属性，不能误撤回有效路由。
   eBGP 的 LOCAL_PREF/反射字段直接丢弃；NEW peer 携带 AS4_PATH/AS4_AGGREGATOR 也丢弃，不把不应使用的辅助值当成当前政策。
   path 提供按 RFC 6793 重建的有效路径，aggregator 提供按聚合器覆盖规则选定的节点；原 AS_PATH/AGGREGATOR 及两种辅助属性不混入普通保留序列。
   按撤回处理时不交出有效路径/聚合器；AS 号去环决策与传播仍须后续路由 owner 执行，不能把路径成员查询当成准入已经完成。
3. 有宣告时要求 ORIGIN/AS_PATH，基础 IPv4 宣告还要求 NEXT_HOP，iBGP 还要求 LOCAL_PREF；缺失按 TreatAsWithdraw。
   只撤回或 EoR 不伪造必需属性。多个错误取更强动作，不因先遇到可恢复错误跳过后续严重错误。
   属性 framing 截断依靠外层 Total Attribute Length 定位基础 NLRI；已辨认的 MP NLRI 也保留，不猜测重新同步位置。
   需要按撤回处理却没有可辨认的 reachable NLRI 时重置，不能忽略报文而保留旧路由；仅丢弃属性的错误不扩大为撤回。
4. MP 共同 framing 校验后才检查地址族/SAFI 协商范围，不对未知族套用普通前缀解释；当前只接纳已协商的双栈 unicast。
   IPv4 MP 可用四字节 IPv4 下一跳，跨族授权后也可用十六或三十二字节 IPv6 下一跳。IPv6 NLRI 只接受后两种长度，首地址非链路且非 mapped，第二个地址为 link-local。
   不能可靠定位 NLRI 的 MP 头/长度、错误 flags 或非法前缀导致 3/9 重置并引用原属性；基础 NLRI 非法导致 3/10。
   位置明确但地址非法的下一跳使整批按撤回处理；接口 zone、直连/eBGP 地址语义及可达证明仍须 transport/RIB owner 检查。
5. changes 先给全部显式撤回，再给宣告；TreatAsWithdraw 将每条可辨认宣告转换为撤回，不能只丢弃当前输入。
   整批决定必须由后续路由 owner 应用并发布，相同前缀的宣告覆盖本消息的显式撤回，不能逐项发布半个批次。
   空基础 UPDATE 或唯一空 MP_UNREACH 提供相应族 EoR 标记；不由此引入跨重启恢复或 Graceful Restart。
   原包和错误编号供运行时诊断留证，属性 framing 错误另有明确标志；原生结构化日志尚未接入，不声称已满足运行时诊断验收。

## AS4 接收重建

system/bgp::path 拥有有效 Path/PathSegment 视图；packet-wire 仍只拥有原始段的格式。ReceivedUpdate 完整捕获属性后一次选定路径和聚合器，不保留辅助接口双轨。
1. NEW peer 的辅助属性在接收裁决中丢弃；OLD peer 两种聚合器同时有效时，基础 ASN 非 AS_TRANS 则忽略两种 AS4 信息，保留基础聚合器/路径。
   基础 ASN 为 AS_TRANS 时改用辅助聚合器并正常重建路径；两者 Partial 取并集，不能清除上游不完整信息。仅有辅助聚合器时不凭空生成基础属性，只有基础值时保留它。
2. 序列逐 AS 计数、集合为一跳、联盟段为零。辅助路径跳数超过基础值则忽略；其联盟段去掉后为空也保留基础路径。
   否则保留基础路径前部差额再拼接辅助段，边界可截短序列、不可拆集合；基础前导/与完整保留段相邻的联盟段保留，位于被替换尾部之后的段不保留。
3. hop_count 保留基础选路长度，contains 检查重建后的全部段，支持后续四字节 AS 去环；auxiliary_partial 只保留实际参与重建的辅助属性标志，忽略的辅助属性不污染元数据。
   需跨消息保活时由 PathPool 规范化/共享，联盟成员准入由可信会话关系约束；Aggregator 是含 ASN/Identifier/Partial 的有效语义值，不再使用丢失传播标志的二元组。
   借用视图的 Eq 只比较其表示，不是路径集合排序/去重或相邻序列合并后的语义等价关系，不能直接充当属性驻留的 canonical key。

## AS4 发送方向

Path::emit_attributes 接受最终出口路径、聚合器及方向 AsnWidth；原生出口复用同一 emit_path_attributes，沿 StoredPath::emit_export 借用标量 prepend，不复制整条路径。
1. NEW 方向写四字节基础 AS_PATH/AGGREGATOR，不附两种辅助属性。OLD 方向基础路径用两字节 AS，不能表示的普通 AS 置为 AS_TRANS。
   只有普通路径含不可映射 AS 才附四字节 AS4_PATH，保留完整普通路径、剔除联盟段；普通 AS 全部可映射时不发送辅助路径。
   不可映射聚合器在基础属性中使用 AS_TRANS，同时携真实 AS4_AGGREGATOR；可映射或缺失聚合器不额外携带辅助聚合器。
2. OLD 方向不能通过辅助路径恢复不可映射联盟成员，按 RFC 6793 的联盟过渡约束拒绝这种输入，不把它静默映射为 AS_TRANS。
   AS 0、属性值/完整属性序列超过 u16 及容量不足均在整批写入前失败，输出不变；原生外部出口 prepend 本连接公开 AS 并去掉联盟内部段；成员间出口和逐目标拒绝见[联盟契约](bgp-confederation.md)。
3. packet-wire 的 AsPath::encoded_len/emit 接受可重复遍历的段/AS 迭代器；旧切片入口已替换，不保留另一份编码实现。
   Attribute::encoded_len/emit_with 唯一拥有短/扩展属性头，既有 Attributes::emit 也走此入口；值回调在尺寸预检后只写精确目标区间且不能返回失败。
   聚合器布局/尺寸也由 packet-wire 唯一编码。BGP 只选择语义值，不复制字段布局，不建立完整 AS 数组、中间属性缓冲或逐消息堆分配。

## 跨消息路径驻留

PathPool 是单个 BGP actor 的路径内容 owner；StoredPath 是一个可克隆指针，不复制 ASN、增加逐前缀堆节点或保活整个池。
1. 在 AS4 重建后捕获规范路径：相邻同类普通/联盟序列合并；普通/联盟集合排序去重，但相邻集合不合并，序列重复 prepend 不删除，集合与序列的选路代价不变。
   先用固定 255 项集合窗口计算实际 AS/段数，再可失败地按规范值预留两个紧凑向量，避免重复项或碎片化输入造成长期空余容量。
   AS 号为 u32，段只保存类型与 u32 结束索引；有效输入来自有消息长度上限的已重建路径，不按协议栈对象大小放大逐路由表示。
2. 规范内容通过已有 FallibleMap 的 AVL 比较驻留，不新增无随机种子的散列表或未经验证的 hash 算法。
   内容比较为 O(B)，查找/删除最多 O(log U) 次比较；U 为活跃不同路径数，B 为一次路径内容比较量，不按全部路由扫描。
   key 保活不可变规范值，value 只弱引用共享 Resident；Resident 又弱引用索引，最后一个路由引用 Drop 立即精确删除对应节点，没有引用环、后台清扫或死 key。
3. Rc/RefCell 限于同一 actor，类型不允许跨线程发送，没有全局缓存/新锁。查找与提交的借用均不跨分配、外部回调或 Resident 析构；所有可失败分配在发布前完成，失败保持旧索引/句柄不变。
   池先退出时弱 owner 无法升级，已有句柄仍保活规范数据；未发表候选析构只会尝试移除不存在的 key。并发 actor/线程不得共享这个可变索引。
4. StoredPath 的 Eq/Ord 比较规范内容，Ord 只用于身份/索引而非路径优劣；其发送按 255 项重新分段，复用 Path 的唯一 AS4 投影。完整属性通过 RouteAttributes::emit_path_attributes 提供聚合器/Partial，不把传播元数据塞进 ASN 内容身份。
   三个路径驻留用例覆盖分段/集合表示复用、序列/集合边界保持、最后引用/池退出及六百 AS 合并后 OLD/NEW 编码再重建的同一对象复用。

## 跨消息完整属性驻留

AttributePool 拥有一个 actor 的完整属性、独立路径及三类团体集合；RouteAttributes 为一指针不可变引用，不按前缀复制属性包。
1. intern 只捕获确有已接纳宣告的 ReceivedUpdate；仅撤回、EoR、TreatAsWithdraw 返回 None，不创建属性/路径对象，也不代替 RIB 的撤回处理。
   路径先经 PathPool 共享；NLRI、MP NLRI 和下一跳从身份中剥离，属于各条路由。ORIGIN、MED/LOCAL_PREF 的缺失/显式值、ATOMIC_AGGREGATE、有效聚合器均保留，不暗中添加入口政策缺省值。
2. 普通/扩展/大团体分别按其完整值排序去重，按紧凑规范值驻留；临时排序向量的重复项空间不进入长期对象。
   团体、反射列表与未知 payload 分组件共享，不因标量字段不同而复制内容；空组件用 None，不创建空对象。扩展团体的跨 AS 传播筛选仍属出口政策。
   ORIGINATOR_ID 与 CLUSTER_LIST 保留；反射链保留顺序和重复，不能套用团体集合归一化。未知 optional transitive 按 code 排序、保留精确值，供传播的视图按 RFC 4271 置 Partial；未知 non-transitive 不进入驻留。
3. 已识别可传递属性的 Partial 不得清除；AS4_PATH 标志与 ASN 身份分开持有，聚合器标志归 Aggregator。is_partial 与 emit_path_attributes 读取同一个内容对象，不另存人工同步的发送状态。
   路径、团体、完整属性的共享索引统一使用 crate 私有 residency 机制；每个 Pool<T> 只容纳不可变规范内容。引用图为属性到路径/团体/反射列表/未知 payload，禁止同池自引用；索引不持强句柄，不执行后台扫描。
4. 所有捕获/节点分配可失败，索引借用不跨分配或内容析构。中途失败时候选的子组件引用自动退回；最后一个完整属性引用释放时，未被其他属性使用的子组件也立即退驻留。
   池先退出不使既有 RouteAttributes/子组件引用失效；Shared 的 Eq/Ord 有同一对象快速路径，跨池仍比较规范内容，不把指针数值当作身份。
   三个完整属性用例经生产接收裁决保护重排/重复团体复用、不同 MED 的子组件共享、反射顺序、Partial/缺失值区分、未知属性保留、撤回不驻留及嵌套释放/池退出。

## 邻居接收表

AdjRibIn 是每个邻居的原始双栈 unicast 候选 owner；其 actor 绑定会话/邻居/路由域身份，本表不重复保存需要同步的会话参数。
1. IPv4/IPv6 分别以地址、长度和可选路径标识为键，通过可失败 AVL 增删。相同前缀的路径连续，单次下界查询后遍历该前缀所有路径。路径编号 0 与普通 NLRI 的无编号区分。
   每条 ReceivedRoute 只持共享 RouteAttributes 引用与自己的 NextHop。Adj-RIB-In 保留协议接纳的原始候选，不等于通过入口政策、AS/反射去环或可达性准入；这些须进入后续 Loc-RIB 决策。
2. apply 只收同一邻居的一份完整 ReceivedUpdate。按前缀和路径标识去重，再捕获一次属性并准备全部新节点和结果向量；所有可失败操作在旧路由修改前完成。
   同报文的宣告覆盖同身份的撤回，重复项保留最后一个决定。前缀相同、编号不同的路径独立增删。RFC 4760 对跨 MP/基础区间的同族重复行为未定义。
   无变化的最终属性/下一跳及不存在的撤回不进入结果；结果按前缀排序去重，只为实际变化分配容量，供后续精确触发选路，不给重复/未知前缀发送伪变更。
3. 提交只有预分配节点填入、替换及删除，独占借用/同步流程内无用户回调，不再分配；OOM 保留原表和旧属性引用，未发表候选自动释放。
   调用者不得静默跳过失败批次继续接收并保留陈旧路由，必须由后续 actor 执行有界背压或会话终止义务。仅撤回/EoR 不驻留属性，TreatAsWithdraw 真实删除可辨认前缀的既有宣告。
4. retire 仅移动两个表的所有权，当前邻居立即变空，不分配或复制逐路由数组；返回旧表供全局选路/来源撤回遍历，属性随最后一个实际引用释放。
   原生 actor 保留全局撤回工作到来源确认。get 按前缀和路径身份精确查询，iter 借用属性。路径编号只用于识别宣告，协议选路按路径的实际属性和可达性裁决。

宿主接收表用例沿生产 OPEN、UPDATE 与选路入口覆盖普通双栈、逐路径撤回与重选，以及共享引用寿命。实际来宾与 FRR/BIRD 互通仍待验收。
OPEN/UPDATE 用例共用 bgp_peer 夹具，仅复用既有握手/输入路径，不在生产代码插入测试入口；OOM 原子性由全部分配前置及现有 FallibleMap prepare/commit 语义审查，不宣称已完成故障注入验收。
双栈 Loc-RIB 来源、逐邻居入口和出口策略、Adj-RIB-Out、反射传播及 TCP 已接入。百万前缀加载和传播仍待整机验收。

## 最佳路径选择核心

selection 拥有 RFC 4271 §9.1.2.2 / RFC 4456 的纯选择过程，不拥有政策、下一跳解析结果、Loc-RIB 或发送状态。
SelectionContext 只捕获有效本地 AS/Identifier 与可选有效 RR cluster ID；None 表示不是 RR，配置 owner 负责投影缺省 cluster ID，不在选择器内另存配置。
1. Candidate 属于同一前缀和路由域，每个邻居可有多条路径。候选携不可变 Peer/RouteAttributes、后政策逻辑下一跳、Phase 1 degree 与自身的权威可达性结果。
   degree 越大越优，None 为政策拒绝、Some(0) 仍可用，不能直接拿统一 RIB 的管理距离填入。PeerKind 由配置/会话关系给出，MED 的相邻 AS 则按实际 AS_PATH 确定，不能用 transport peer ASN 替代。
   Reachability 区分不可解析与可解析但无 IGP 代价；Resolved 必须已覆盖“安装本路由后仍可解析”的检查，旧 FIB Forward/随意 Some(0) 不构成准入证明。
2. 首先排除无效邻居、政策拒绝、不可解析、AS 路径存在本地环路的路由（联盟公开身份与成员身份的检查范围见[联盟契约](bgp-confederation.md)），以及本机 ORIGINATOR_ID/本 RR cluster 循环；原始 Adj-RIB-In 不被删除。
   再按最高 degree、最短路径、最低 ORIGIN 消除；AS_SET 一跳，联盟段不占跳数。MED 只在前序幸存者中按相邻 AS 分组，各组保留最小值，缺失为零。
   路径首个普通序列的第一 AS 给出组；跳过联盟段，同成员与其他联盟成员的空路径/前导 AS_SET 按本成员 AS 处理，外部空/集合路径用直接邻居 AS 兜底。
3. MED 后先优先真正外部 eBGP（联盟成员与 iBGP 同级），再比较下一跳 IGP 代价；若此时任一仍可达的幸存者无代价，则跳过整个代价步骤，不能伪造零/无穷大，也不能被早已淘汰的候选影响。
   最后依次比较最低有效 BGP Identifier（ORIGINATOR_ID 优先）、最短 CLUSTER_LIST、最低邻居地址与稳定邻居 ID。仍完全相同的同邻居路径沿接收表稳定顺序裁决。
   MED 条件比较不满足传递性；分组只使用 (相邻 AS, MED) 全序键，再按后续条件选择。
4. Selector 只复用派生标量工作区的容量，进入/返回清空元素，不保活候选引用或缓存赢家；选择不克隆属性、增加逐前缀驻留对象或修改候选/接收表。
   工作区扩容 OOM 直接返回错误，无旧赢家回退。输入满足前提时返回原 slice 的唯一最优索引，全部被拒绝返回 None；rejection 提供相同门槛的首个原因供后续诊断。

五个选择用例用生产 codec/接收/驻留准备属性，受控候选覆盖 MED 循环胜负的所有排列、工作区复用后重算、阶段优先级、集合/空路径/联盟组、未知代价、四字节 AS/反射去环及反射平局顺序。
既有邻居退出用例同时把真实 Session/Adj-RIB-In 的属性与 OPEN 邻居投影交给选择器，检查首选到备用到无候选的重算；政策/可达性仍为受控输入，不虚构原生 NHT 成功。
基础 Phase 1、候选图的安装后递归检查及 双栈来源下发已接通；RR 出口已接通，这些 host 结果不替代实际协议和路由服务验收。

## Loc-RIB 持有与发表边界

LocRib 拥有每个前缀的当前协议选择。配置需要多路径发送时，同一确认结果还保留通过入口、去环和安装后可达性检查的备选路径。
1. 每条确认路径持有共享属性、来源身份、后政策逻辑下一跳和 degree。备选与赢家共用同一存储及确认边界；普通单路径只保留赢家，不分配路径数组。
   接收表退出不释放 Loc-RIB 持有的属性；原始候选与当前选择有不同职责，不能把两表当作人工同步的同一份状态。立即出口/递归图仍归统一 routing-rib，本表不另存 FIB。
2. prepare 从可失败迭代器捕获当前批次的已选择结果，调用者可逐前缀复用候选/Selector 工作区；不收集全表候选矩阵或复制当前 Loc-RIB。
   同前缀最后一项生效，None 撤回。选用路径或备选集变化均登记出口；仅改变备选时无需重新发布未变的转发来源。
   非规范前缀、错误地址族、IPv6 网段使用 IPv4 下一跳及上游选择或分配失败不修改旧表。节点和结果容量均在发布前准备好。
3. 来源正文逐地址族完整替换，因此每个 LocRibUpdate 只属于一个地址族，两族分别确认；配置 owner 仅在有 IPv6 邻居能力配置时授予 IPv6 来源，正文不能提升权限。
   同轮先确认 IPv6，再确认可能依赖该 IPv6 路径的 IPv4。某一族失败不撤销此前已确认的另一族。
   guard 独占借用当前 LocRib，形成不靠 generation/pending flag 同步的唯一租约。iter 合并该族旧表与已准备增量给出完整冻结候选视图，不复制逐路由 DTO，也不扫描另一族的表。
   调用者必须经现有统一 RIB 来源通道发表该视图；确认成功后 commit 消费 guard，只填入已预留节点、替换/删除并返回实际变化前缀，不分配、不发 RPC/调用用户回调。
   取消/确定未发表的失败丢弃 guard 只释放候选，旧表仍在；发表成功后不得省略本地 commit。传输结果未知不能按未发表处理或盲目继续接收，须由来源 owner 完成确认/退休协调。
   must_use 防止静默丢弃准备结果，但不伪造外部确认能力。
4. 纯库提供协议状态、候选视图与来源编码；原生 route_selection 沿授权来源能力发表，纯库不调用 RPC 或直接写 FIB。
   新 Loc-RIB 用例沿实际接收表/选择核心取得结果，覆盖双族独立视图、批次提交/取消、无变化、最后决定、错误族/前缀/上游失败和接收表退出后的强引用/撤回释放。
   原生产 NET 用例使用配置中的入口策略和候选图检查后发表；原生 RPC、内存故障注入与双栈真实转发尚未验收。

## 来源正文投影

LocRibUpdate::encode_source 沿 router-protocol::routing::Batch 的唯一 codec 输出单族完整替换，不拥有来源身份、能力或新提交状态。
1. peers 按稳定邻居 ID 借用冻结 SourcePeer；距离来自配置，minimum 来自实际来源授权，两者均非零，距离不得优先于授权下界。
   来源内每前缀只有一个 BGP 赢家，metric 固定为零；BGP degree/MED/路径长度已在协议选择中裁决，不能泄漏成不同意义的原生管理距离或跨 AS 代价。
2. 普通地址保留 Recursive，由统一 RIB 重新解析。IPv6 成对下一跳只有在调用者确认共链路且给出实际接口时采用 link-local Direct；否则以非 link-local 地址递归。
   只有 link-local 且缺少范围时拒绝，不能猜接口或把它当无 zone 的递归地址。next_hop_interface 必须属于实际下一跳的链路，不能仅因为 TCP 会话有绑定设备就填入。
   未指定、组播、有限广播及错误辅助地址拒绝。安装检查与来源编码使用同一目标，带范围的 Direct 由统一 RIB 检查该接口的实际邻接。
3. 单批只为不同管理属性/目标维护临时去重索引与稠密字典；下一跳组直接借用单成员字典，候选路由在预检/生成时重放冻结视图。
   没有逐前缀 DTO、另一份下一跳视图数组、跨批缓存或新锁。字典/正文任一步失败都丢弃本批资源，Loc-RIB 不变，空视图编码为真实撤回正文。

既有 Loc-RIB 用例扩展覆盖共享字典、距离授权、双族隔离、接口范围和失败保留；NET 来源用例复用同一 Session 夹具，串联接收、选择、来源捕获、实际 NET 发布及退出撤回。
跨族用例覆盖带范围邻接的安装证明、IPv6-only 出口的 IPv4 流量，以及对端实际解码的发布和撤回。
既有来源预备用例同时检查新图观察、旧图不发表、NET 激活与撤销；原生来源能力支持候选观察和三阶段确认，详细边界见[来源契约](router-configuration.md#原生-rib-配置来源)。
来源事务还可在同一候选图上检查每条路由安装后是否形成自递归，保留仍有效的多路径；原生反馈选择及来源装配已使用该能力，仍不能把单次反事实结果当作整批安装确认。
原生 TCP 与来源 RPC 已接入；结果未知时结束域、关闭来源撤回，不盲目提交或重放。真实双栈转发仍未完成。

## 路由域更新顺序

RoutingDomain 统一拥有同一 BGP 路由域的邻居登记、共享属性池、Adj-RIB-In、选择工作区、Loc-RIB 与待发表前缀；不是统一 routing-rib 或 TCP/会话 owner。
1. add_peer 冻结已协商邻居身份及来源距离，不覆盖活动身份；只拒绝复用尚待撤回确认的退休身份，其他新邻居可在 pending 期间登记。
   receive 在修改接收表前按 NLRI 决定数预留工作上界，成功捕获后无分配追加实际变化；多份 UPDATE 可合并，原生 actor 须按有界批次/截止触发发表，不能逐消息完整替换百万路由来源。
   remove_peer 在修改登记前预留并追加全部前缀工作，失败保持旧邻居；成功退休接收表仍保留撤回/重选，旧 Loc-RIB 的共享引用活到来源确认。
   reconsider 接受政策/NHT 前缀，规范校验复用 Loc-RIB 入口；完整捕获后才并入现有工作，失败不覆盖旧工作。
2. prepare 对所属族每个待处理前缀从全部当前邻居收集候选，复用一个候选数组及 Selector；分类回调只提供冻结政策/NHT 的后政策下一跳、degree 与相应证明，不推断可达性。
   当前候选借用原始或已投影的共享属性，ORIGIN/MED 改写已接入，三类团体编辑与 AS 路径编辑也已接入；安装后递归条件与 IGP 代价不能用旧 FIB 或无依据的 Some(0) 替代。来源距离表只为本批从不可变邻居投影，不增加长期同步副本。
3. prepare 先将合并工作排序去重，每个最终前缀只选一次；接收阶段不逐消息重排增长中的表。RoutingUpdate 独占选择/工作，发表在途借用禁止继续修改域，传输 owner 须保留输入并执行背压。
   取消、分类/编码 OOM 或确定未发表的失败保留 pending 和旧选择，可重新准备同一工作。来源确认后 commit 无分配地提交 Loc-RIB 并只退休该族工作，无变化也须消费已处理工作。
   另一族未确认时保留其工作，可继续合并后续输入；不能因先完成 IPv4 就丢掉同消息的 IPv6 更新。最后一项工作退休后释放临时容量，不把全表退休数组变成长期缓存。
   网络结果未知仍归来源 owner 协调，不允许把“guard 可取消”当成外部来源已回滚；当前库不发送 RPC，不增加新锁或后台工作线程。

原邻居退出用例扩展保护取消/失败重试、背压、首选到备用、政策恢复及双族确认；原真实 NET 来源用例由 RoutingDomain 处理接收/选择/退休，不再在夹具手工拼接这一顺序。

## 成本与验证

接收/发送视图只借用调用者输入；迭代重建一个定长地址/段视图，不收集完整前缀/AS/属性数组；明确调用 PathPool::intern 后才按不同规范路径拥有 AS 数据。
编码先检查本层负责的尺寸/字段/容量，失败不改输出；随后只写共同头和最终区间，UPDATE 每段复制一次，无隐藏中间完整帧。
原生 actor 持有属性/路径/团体驻留、流缓冲、发送背压及接收路由表；packet-wire 不保留跨消息缓存或恢复状态。
原生运行有一个域线程/Port，socket observer 和 USER 工作各最多一份登记，每邻居固定控制缓冲、至多一帧出口正文及按需收发路由存储，不增加报文转发热路径。
benchmark 决策：会话收发与 RPC 只在控制面，当前先作有界工作/所有权审查；真实全表加载、内存峰值和传播延迟随完整政策/来源服务统一测量，不把 Clippy 当作性能证据。
Adj-RIB-In 的结构预备为 O(P log P + P log R)，另加属性驻留/释放成本；P 为当前消息前缀数、R 为该邻居现有路由数。暂存只随当前消息变化，退表移动无分配，旧表释放按实际路由数执行；百万前缀内存和吞吐仍须随服务全表加载测量。
最佳路径工作区与单个前缀的候选数 K 成正比，不随总前缀数复制数组；除路径检查外为 O(K log K) 分组排序/线性消除，已有容量足够时不分配。复用容量仅在 Selector 生命周期内保留，不承载权威状态。
Loc-RIB 准备为批次 B 的 O(B log B + B log L)，另加引用释放成本；L 为当前记录数。候选视图单次为 O(L_family+B)，只合并所属地址族，不建立另一份完整 DTO；当前节点/逻辑下一跳的百万前缀内存仍须随完整服务实测，不能宣称已经最优。
来源投影重放所属族视图，按邻居/字典索引查询，成本为 O((L_family+B) × log(P+A+H))；P/A/H 为邻居、不同属性与不同目标数，临时字典为 O(A+H)，另有最终正文。
此为完整来源控制面替换，不进入报文热路径；沿既有全表加载/更新基准统一测量峰值和吞吐，不另建小用例阈值或宣称已实现增量来源发布。
路由域为变化前缀保留 O(B) 工作；每前缀跨 P 个邻居查询接收表并复用 O(K) 候选工作区，K 是该前缀的实际路径数。额外路径开销限于控制面，沿既有全表加载及传播基准实测。

驻留增加路径集合的有界排序、团体集合的 O(C log C) 排序和 O(log U) 内容索引；分配只在跨消息捕获时发生，不在逐前缀引用/克隆或路径发送中分配。规模成本须随真实 RIB 全表加载一起测量，当前不虚设独立阈值或宣称最优。
`netstack-unit/tests/bgp_formats.rs` 直接调用生产 codec，保护拆包/粘包、普通/扩展长度、双栈所有前缀边界、两种 AS 宽度、
独立属性失败、有效 MP 前缀后截断、输出失败不变及有限嵌套变异；现有 IP/UDP fixture 不覆盖这些新字节边界。
会话夹具直接用同一生产 OPEN codec 驱动 Session，检查握手、真实发送计时、零 hold/被动模式、超时撤回义务、方向授权退休、错误数据及碰撞决定。
状态转换为 O(1)，OPEN/UPDATE 的字段检查线性于输入；属性编号集合固定 32 bytes，不按前缀/属性建堆节点。
UPDATE 冻结视图只持固定四个 NLRI 区间及借用元数据；Effects 的两槽成本有界、不随前缀条数增加，因此此 enum 使用最窄的 large_enum_variant expect，避免为每消息装箱分配。
接收完整检查与后续属性驻留是不同阶段；不为减少一次材料化遍历而在本层创建持久属性副本。诊断编号与前缀按需迭代，完整报文不复制。
