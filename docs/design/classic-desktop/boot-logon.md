# 开机、登录、注销与关机

画面序列与文案按简体中文 Windows 2000 Professional 还原，品牌按 [README.md](README.md) 替换。
每个画面写明由哪个组件绘制，组件命名见 `docs/plans/classic-desktop.md`。
本文件所有中文文案的逐字内容均为**待核**（来自记忆与截图描述），画面结构与按钮集合为确定。

## 画面序列

| # | 画面 | Windows 2000 对应阶段 | LiteOS 阶段 | 绘制者 |
|---|---|---|---|---|
| 1 | 文本进度条 | NTLDR 加载内核 | kernel 启动 | `kernel drm/boot_screen` |
| 2 | 启动画面 | 内核初始化、服务启动 | init / `rcS` / 服务 | `compositor boot.rs` |
| 3 | 欢迎使用（Ctrl+Alt+Del） | Winlogon 等待安全注意序列 | 会话开始 | `logon` |
| 4 | 登录到 LiteOS | GINA 登录对话框 | 认证 | `logon` |
| 5 | 正在加载您的个人设置 | 加载用户配置 | 拉起 `desktop` | `logon` |
| 6 | 桌面 | Explorer 外壳 | `desktop` 首帧 | `desktop` |

画面之间的切换：1 → 2 无闪烁接续（同一显示模式与背景色，compositor 接管 scanout 时先画与 kernel 最后一帧
完全相同的内容）；2 → 3 允许一次全黑帧（Windows 2000 在此处同样黑屏一下，待核）；3 之后全部在桌面背景色上进行。

## 1. 文本进度条（kernel）

还原 NTLDR 的文本模式进度条（待核：以下布局来自截图描述）。

1. 全屏黑色背景。
2. 屏幕底部倒数第二个字符行左侧显示白色文字 `Starting LiteOS...`（NTLDR 是文本模式，中文版此处同样是英文）。
3. 最底部一行是全宽进度条：白色外框，内部用白色实心块从左向右填充；填充比例由 kernel 启动里程碑推进。
4. 文字使用 8 × 16 的 VGA 风格等宽点阵字体（复用 `terminal-font`），按显示 scale 整数放大。

## 2. 启动画面（compositor）

本地原版素材使用 [assets.md](assets.md#本地原版素材) 中的 `boot-scene`：640×480 完整画面，
已经包含产品标志、下方蓝色条带、灰色状态区与进度条外框。它不能作为中央 `boot-logo` 贴入另一套背景，
也不按下面原创素材的估计比例裁剪。动态进度与文案按原图像素坐标实现，未核实的位置保留"待核"标记。

以下是仓库原创画面的布局草案（待核），本地原版按其实际资源构图验收：

1. 全屏分为上下两个区域：上部 3/4 为白色，下部 1/4 为深蓝渐变条带，两者都铺满整个屏幕宽度。
   区域按物理像素划分，不依赖固定构图尺寸，因此任何分辨率下都是全屏画面。
2. 上部区域中央放置位图 `boot-logo`（LiteOS logo、产品名"LiteOS 2000 Professional"与小字"基于 LiteOS 技术"），
   按显示 scale 选用 1x 或 2x 素材（见 [assets.md](assets.md)）。
3. 条带中居中显示文字"正在启动..."，其下是分段进度条：由若干蓝色方块组成，从左向右逐块点亮；进度由 init
   阶段的里程碑推进，至 compositor 收到 `desktop` 首帧前达到 100%。文字与进度条按显示 scale 放大。
4. 左下角小字"版权所有 © LiteOS 贡献者"。

## 3. 欢迎使用（logon）

1. 桌面背景色 `#3A6EA5` 全屏，不显示图标与任务栏。
2. 居中对话框，标题"欢迎使用 LiteOS"，无关闭按钮。顶部是 `logon-banner` 横幅位图（产品名与 logo）。
3. 横幅下方左侧是 `ctrl-alt-del` 键盘图示（48 × 48），右侧文字：
   "按 Ctrl-Alt-Delete 开始。"
   "要求按 Ctrl-Alt-Delete 键可以确保在登录时的安全性。有关详细信息，请单击“帮助”。"
4. 底部按钮："帮助"。
5. 仅响应 Ctrl+Alt+Del（由 compositor 作为安全注意序列直接投递给 `logon`，其他进程收不到也无法伪造）。

## 4. 登录到 LiteOS（logon）

1. 对话框标题"登录到 LiteOS"，顶部同样的横幅位图。
2. 字段：
   - "用户名(U):" 文本框，默认填上一次登录的用户名。
   - "密码(P):" 密码框，以 `*` 显示。
3. 按钮："确定"（默认按钮）、"取消"、"关机(S)..."、"选项(O) <<"。
4. "选项(O) <<"折叠时变为"选项(O) >>"，展开后显示"登录到(L):"下拉框（只有本机名一项）与
   "使用拨号网络连接登录(D)"复选框（灰显，本期不提供）。
5. 认证失败：消息框"登录消息"——"系统无法让您登录。请确定您的用户名及域是正确的，然后再次键入密码。
   字母密码必须使用正确的大小写。"，图标为警告，按钮"确定"；关闭后清空密码框并聚焦。
6. 认证依据 `/etc/passwd` 与 `/etc/shadow`；成功后以该用户身份拉起 `desktop`。

## 5. 正在加载您的个人设置（logon）

桌面背景色上居中的小对话框，无标题栏按钮，文字"正在加载您的个人设置..."；`desktop` 首帧送达后关闭。

## 会话内 Ctrl+Alt+Del：LiteOS 安全

1. 桌面变暗（待核：Windows 2000 是切换到独立的安全桌面，背景为桌面色），居中对话框"LiteOS 安全"。
2. 上部"登录信息"分组框："您以 <用户名> 身份登录。"、"登录日期: <日期时间>"。
3. 中部文字："使用任务管理器关闭不响应的应用程序。"
4. 按钮（两行三列）："锁定计算机(K)"、"注销(L)..."、"关机(S)..."、"更改密码(P)..."、"任务管理器(T)"、"取消"。

锁定计算机后显示"计算机已锁定"对话框：说明只有当前用户或管理员可以解锁，"按 Ctrl-Alt-Delete 解锁"；
解锁对话框"解除计算机锁定"要求输入当前用户密码。

## 关闭 LiteOS

由开始菜单"关机(U)..."或 Alt+F4（焦点在桌面时）打开：

1. 对话框"关闭 LiteOS"，顶部横幅位图。
2. 左侧 `shutdown` 图标（32 × 32），右侧"希望计算机做什么(W)?"下拉框：
   - "注销 <用户名>"——"结束会话，保持计算机运行并处于开机状态。"
   - "关机"——"结束会话并关闭 LiteOS，以便您可以安全地关闭电源。"
   - "重新启动"——"结束会话，关闭 LiteOS，然后再次启动 LiteOS。"
   下拉框下方显示所选项的说明文字。
3. 按钮："确定"、"取消"、"帮助"。下拉框默认值为上一次的选择。
4. 确认后依次显示"正在保存您的设置..."、（注销时）回到"欢迎使用"画面；（关机时）kernel 关闭电源。
