# 交互清单

逐条验收。每条注明 owner（实现它的组件）与置信度；验收方式是在 LiteOS 中按"操作"执行并比对规格要求的"结果"。

## 窗口管理（owner：compositor `window/`）

| # | 操作 | 结果 | 置信度 |
|---|---|---|---|
| W1 | 单击窗口任意位置 | 激活并置顶；标题栏变为活动渐变；原活动窗口变为非活动渐变 | 确定 |
| W2 | 拖动标题栏 | 移动窗口；默认"拖动时显示窗口内容"开启，窗口实时跟随 | 待核（默认值） |
| W3 | 关闭"拖动时显示窗口内容"后拖动 | 只移动一个 `XOR` 绘制的空心矩形框，松开后窗口跳到新位置 | 确定 |
| W4 | 拖动边框或角 | 对应方向缩放，光标变为相应双向箭头 | 确定 |
| W5 | 双击标题栏 | 最大化 / 还原切换 | 确定 |
| W6 | 双击标题栏左侧图标 | 关闭窗口 | 确定 |
| W7 | 单击标题栏左侧图标或 Alt+Space | 弹出系统菜单：还原(R)、移动(M)、大小(S)、最小化(N)、最大化(X)、分隔线、关闭(C) Alt+F4 | 确定 |
| W8 | 系统菜单"移动"后用方向键 | 键盘移动窗口，Enter 确认、Esc 取消 | 确定 |
| W9 | 最小化 / 还原 | 一个标题栏大小的矩形在窗口与其任务栏按钮之间移动的动画（约 200 毫秒） | 确定（动画存在）/ 待核（时长） |
| W10 | 最大化 | 窗口填满除任务栏外的工作区，边框移出屏幕外，最大化按钮变为还原按钮 | 确定 |
| W11 | Alt+F4 | 向活动窗口发送关闭请求 | 确定 |
| W12 | Alt+Tab（按住 Alt） | 屏幕中央出现灰色面板：最多 7 列 32 × 32 图标网格，当前项有方框，下方显示其标题；松开 Alt 切换 | 确定 |
| W13 | Alt+Shift+Tab | Alt+Tab 反向 | 确定 |
| W14 | Alt+Esc | 不显示面板，直接把活动窗口放到最底并激活下一个 | 确定 |
| W15 | 新窗口出现 | 层叠放置（相对上一个新窗口右下偏移一个标题栏高度），并获得焦点 | 待核 |
| W16 | 全屏程序（如游戏） | 覆盖任务栏；Alt+Tab 可切出，切出时程序最小化 | 确定 |

## 键盘导航提示（owner：classic-ui）

| # | 操作 | 结果 | 置信度 |
|---|---|---|---|
| N1 | 用鼠标打开窗口或菜单 | 快捷键下划线与焦点虚线框**隐藏** | 确定（Windows 2000 引入，默认开启） |
| N2 | 按下 Alt 或用 Tab 移动焦点 | 该窗口内显示下划线与焦点框，直到窗口关闭 | 确定 |

| N4 | 对话框中 Enter / Esc | 触发默认按钮 / 取消按钮 | 确定 |
| N5 | 对话框中 Alt+字母 | 触发带该下划线字母的控件 | 确定 |
| N6 | 单选按钮组中方向键 | 在组内移动并选中 | 确定 |

## 菜单（owner：classic-ui；开始菜单由 desktop 使用同一实现）

| # | 操作 | 结果 | 置信度 |
|---|---|---|---|
| M1 | 打开菜单 | 默认"滚动"动画：从锚点方向展开（约 150 毫秒）；可在"显示 属性→效果"切为"淡入"或关闭 | 待核（默认效果与时长） |
| M2 | 悬停有子菜单的项 | 400 毫秒后展开子菜单；向子菜单斜向移动鼠标时不会误关 | 确定 |
| M3 | 菜单中方向键 | 上下移动选中项，右键展开子菜单，左键收回，Enter 执行，Esc 逐级关闭 | 确定 |
| M4 | 单击菜单外 | 关闭整个菜单链，该次单击不传递给下面的窗口 | 确定 |
| M5 | 菜单项按下字母 | 执行带该下划线字母的项；多项同字母时依次循环 | 确定 |
